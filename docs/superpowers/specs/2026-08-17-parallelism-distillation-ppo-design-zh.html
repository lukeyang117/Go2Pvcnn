Parallelism 学生模型 PPO 蒸馏设计

目标：让不输入 reference trajectory 的学生策略，在保留 teacher 动作先验的同时，通过环境奖励学习真实移动、速度跟踪和稳定步态。

适用范围：当前 parallelism mixed-terrain distillation 任务。旧的普通 PPO 任务和 Parallelism planner 不修改。

一、当前问题

当前学生模型主要依靠 teacher action 做 imitation。学生接管后，虽然仍然计算 teacher action，但学生动作误差会上升，导致足端跟踪和移动稳定性变差。

本次设计增加 PPO 梯度，让学生同时受到真实环境反馈。学生不需要获得 reference trajectory，teacher 只作为特权监督信号。

二、输入与动作定义

Student actor 输入

  • 高程图和语义地图
  • base angular velocity
  • projected gravity
  • joint position
  • joint velocity
  • velocity command：vx、vy、vyaw
  • previous action

不输入真实 root 线速度 base_lin_vel，但保留真实 root 角速度 base_ang_vel。同时不输入 reference joint、reference foot、reference root position 或 reference root rotation。

Teacher 输入

Teacher 继续使用当前特权观测，包括 Parallelism reference trajectory。Teacher 网络冻结，只提供确定性动作目标。

teacher_action = teacher.act_inference(teacher_obs)

teacher action 不使用 std 采样。

Critic 输入：Parallelism 特权观测

Critic 不与 student actor 共用输入。Critic 使用 teacher observation 估计当前状态价值，显式接收 Parallelism 的 reference 信息。

critic_obs =
    teacher_elevation_semantic_map
    + teacher_state

teacher_state =
    base_ang_vel
    + projected_gravity
    + joint_pos
    + joint_vel
    + previous_action
    + base_lin_vel
    + parallelism_ref_joint_pos
    + parallelism_ref_joint_vel
    + parallelism_ref_root_pos
    + parallelism_ref_root_rot

reference 项只进入 critic，不进入 student actor，也不作为 play 部署输入。

Critic 可以看到真实 root 线速度和角速度；这些速度属于特权 critic 输入，不能回流到 student actor。

三、std 和动作流

训练时的 student

student_mean = student.actor(student_obs)
student_std = exp(student.log_std)
student_action ~ Normal(student_mean, student_std)

带 std 的 student action 用于输入 IsaacSim、计算 PPO 的 log probability，并参与 rollout。std 保留为可学习参数，初始建议为 0.3。

训练时的 teacher

teacher_action = teacher.act_inference(teacher_obs)

teacher 使用确定性均值动作，不经过 teacher std 采样。

Imitation loss

L_imitation = MSE(student_mean, teacher_action)

imitation 比较 student 的均值动作和 teacher 的确定性动作，避免探索噪声污染蒸馏目标。

训练时的环境动作混合

Teacher 和 student 每个 iteration 都同时计算，但进入 IsaacSim 的动作按照训练进度在环境维度上混合。这里的“混合”是选择不同环境执行不同策略，不是对两个动作做数值加权平均。

progress = iteration / max_iterations

if progress < 0.30:
    teacher_ratio = 1.0
elif progress < 0.80:
    teacher_ratio = 1.0 - (progress - 0.30) / (0.80 - 0.30)
else:
    teacher_ratio = 0.0

student_ratio = 1.0 - teacher_ratio

约 teacher_ratio * num_envs 个环境：
    env_action = teacher_action

约 student_ratio * num_envs 个环境：
    env_action = student_action

同一个 rollout 中所有环境使用同一个 teacher_ratio。具体环境通过批量 mask 分配给 teacher 或 student，使 teacher 环境数与 student 环境数之和等于总环境数。teacher action 不与 student action 做线性平均。

前 30% 完全由 teacher 带领环境，30%～80% 平滑增加 student 的真实环境经验，80% 后完全由 student 控制。

控制器分配以 episode 为单位保持不变：一个环境一旦被分配给 teacher，本 episode 剩余时间始终执行 teacher；被分配给 student 的环境始终执行 student。只有环境 reset 并开始新 episode 后，才按照当时的 teacher_ratio 重新分配。

训练时的 loss 使用

两种 loss 在整个训练期间都存在，不通过训练阶段硬开关。区别只根据当前 transition 实际由谁控制环境来处理 PPO actor 数据：

所有样本：
    imitation_loss = MSE(student_mean, teacher_action)

teacher 控制的样本：
    imitation loss：使用
    PPO actor surrogate：不使用
    critic value loss：使用

student 控制的样本：
    imitation loss：使用
    PPO actor surrogate：使用
    critic value loss：使用

teacher 控制的动作不是 student policy 采样得到的动作，不能直接用于 student 的 PPO policy ratio。rollout 需要保存 ppo_active_mask；该 mask 只屏蔽 teacher 控制样本的 PPO actor surrogate，不屏蔽 imitation loss 和 critic value loss。

Teacher 和 student 的 critic 输入都通过 IsaacLab 的 last_action 观测项读取真实执行动作。因此 teacher episode 的 critic action 始终是 teacher action，student episode 的 critic action 始终是 student action。reset 后第一帧使用环境的初始 action 状态，之后从下一帧开始反映实际执行的控制器动作。

Play 时

student_action = student.act_inference(student_obs)
student_action -> IsaacSim

play 永远使用 student mean，不采样 std，teacher 不参与学生动作输入，也不执行训练阶段的 teacher/student 环境比例。

四、奖励设计

新增速度奖励

track_lin_vel_xy:
    func = track_lin_vel_xy_exp
    command_name = "base_velocity"
    weight = 1.0
    std = 0.5

track_ang_vel_z:
    func = track_ang_vel_z_exp
    command_name = "base_velocity"
    weight = 0.5
    std = 0.5

track_lin_vel_xy 直接比较当前 policy root 坐标系下的 x/y 线速度和输入命令的 vx/vy。

track_ang_vel_z 直接比较当前 policy root 的 yaw 角速度和输入命令的 vyaw。

奖励与 imitation 的边界

IsaacSim 环境奖励：由速度、reference、足端、关节、碰撞等奖励项共同组成，进入 PPO 的 advantage、return 和 policy/value loss。
Teacher action：不作为环境奖励，不改变 reward；只作为 L_imitation 的监督目标。
最终更新：L_total = ppo_coef * L_PPO(ppo_active) + teacher_coef * L_imitation。

因此学生会同时受到两种约束：PPO 要求 student 实际控制的环境获得高环境奖励，teacher imitation 要求所有环境中的 student 不要偏离 Parallelism 规划动作。

原有奖励全部保留

奖励类别作用是否保留
reference root position / rotation跟踪 Parallelism root 轨迹保留
reference joint position / velocity跟踪规划关节动作保留
reference foot position跟踪规划足端轨迹保留
geometry collision惩罚规划几何碰撞保留
track_lin_vel_xy直接跟踪输入平移速度新增
track_ang_vel_z直接跟踪输入 yaw 速度新增

五、PPO 与 teacher 的联合损失

L_total =
    ppo_coef * L_PPO(ppo_active_mask)
    + teacher_coef * L_imitation(all samples)

其中：

L_PPO =
    policy_surrogate_loss
    + value_loss_coef * value_loss
    - entropy_coef * entropy

PPO 权重

ppo_coef = 1.0

PPO 负责根据速度奖励、reference 奖励、足端奖励和碰撞惩罚纠正学生动作。

Teacher 权重

teacher_coef = 0.5

Teacher 负责保持 Parallelism 规划动作先验，避免 PPO 初期把学生策略带偏。

权重调度

训练阶段ppo_coefteacher_coef目的
前 30%1.0按 teacher_coef 调度环境全由 teacher 控制，student 通过 imitation 学习
30%～80%1.0按 teacher_coef 调度teacher/student 环境比例逐渐交接，student 开始获得 PPO 反馈
80% 以后1.0按 teacher_coef 调度环境全由 student 控制，PPO 主导实际行为

环境动作的 teacher_ratio 调度与 imitation 的 teacher_coef 调度是两个独立参数。前者决定谁进入 IsaacSim，后者决定 teacher 监督信号的梯度权重；两者都复用之前设计中的 iteration 百分比机制。

七、Actor、Critic 和 Teacher

Student actor：只看 student observation，输出带 std 的动作分布。
Student critic：输入 teacher observation，包含高程语义地图、本体状态和 Parallelism reference joint/root 观测，输出 PPO value。
Teacher network：冻结，只输出确定性 teacher action，不参与 PPO 梯度。
Optimizer：更新 student actor 和特权 critic；不更新 teacher。critic 的特权输入不会泄漏到 actor。

九、训练启动与测试策略

测试时不使用 resume

本蒸馏任务的对比测试默认从全新的 student 开始，不使用 --resume，也不加载旧的 student checkpoint。这样可以保证不同测试结果都从相同的 student 初始化状态开始，不受之前蒸馏进度、旧 optimizer 状态或旧 std 的影响。

每次测试启动：
    1. 新建日期/hash 训练目录
    2. student actor 重新初始化
    3. student critic 重新初始化
    4. optimizer 重新初始化
    5. 加载固定 teacher checkpoint
    6. teacher.eval() 且 teacher.requires_grad_(False)
    7. 从 iteration 0 开始训练

启动命令只传入 --teacher_checkpoint，不传入 --resume、--load_run 或 --load_checkpoint。Teacher checkpoint 只用于生成特权 teacher action，不作为 student 的初始化权重。

训练启动形式

python Go2Pvcnn/scripts/train.py \
    --experiment parallelism_tracking_cross_large_complex_distillation \
    --num_envs 1024 \
    --headless \
    --max_iterations 2000 \
    --teacher_checkpoint /path/to/teacher/model.pt

其中 max_iterations 同时用于计算 teacher/student 环境比例调度。比如 max_iterations=2000 时：

  • 第 0～599 iteration：teacher_ratio = 1.0。
  • 第 600～1599 iteration：teacher_ratio 从 1.0 线性下降到 0.0。
  • 第 1600～2000 iteration：teacher_ratio = 0.0。
固定测试原则： 每次测试都使用同一个 teacher checkpoint、同一套环境数量和同一套百分比调度，但 student 从零开始训练；只有完成一次完整测试后，才根据指标决定是否另行进行 resume 实验。resume 不属于本设计的默认验收路径。

十、验证指标

  • Episode_Reward/track_lin_vel_xy：输入平移速度跟踪奖励。
  • Episode_Reward/track_ang_vel_z：输入 yaw 速度跟踪奖励。
  • Metrics/base_velocity/error_vel_xy：实际 root 线速度误差。
  • Metrics/base_velocity/error_vel_yaw：实际 yaw 角速度误差。
  • Distillation/action_mse：student mean 与 teacher deterministic action 的误差。
  • Distillation/teacher_ratio：当前 iteration 进入 IsaacSim 的 teacher 环境比例。
  • Distillation/student_ratio：当前 iteration 进入 IsaacSim 的 student 环境比例。
  • Distillation/ppo_active_ratio：rollout 中实际可用于 PPO actor surrogate 的 student 样本比例。
  • Train/value_function_loss：student critic 的价值误差。
  • Train/surrogate_loss：PPO actor 更新损失。
  • Train/mean_episode_length：学生是否能持续行走。
最终动作原则： 训练时 teacher 和 student 都计算动作；前 30% 环境全执行 teacher，30%～80% 按统一比例分配 teacher/student 环境，80% 后全执行 student。teacher 使用确定性动作，student 控制环境时使用带 std 的动作；imitation 始终计算，PPO actor 只使用 student 实际控制的样本。play 时使用 student mean，不采样 std。
