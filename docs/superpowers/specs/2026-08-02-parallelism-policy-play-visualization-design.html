Parallelism RL Policy 回放与参考规划可视化设计

分支：Parallelism-flat-rl。目标：在真实 IsaacLab 物理 rollout 中同时观察 policy 动作、Parallelism 24 帧参考和逐项 termination。

1. 目标与边界

修改 Go2Pvcnn/scripts/play.py，加入 parallelism_tracking_flat experiment。它加载该实验的 RSL-RL checkpoint，在单环境、非 headless IsaacLab 中运行真实 policy。

此次不修改训练环境、PPO、planner 轨迹、reward 或 termination 阈值。可视化只使用训练时同一套 ParallelismReferenceManager、高程/语义 raycaster 输入和 policy observation 语义。

2. 一致的运行链路

ImGui 速度面板 -> env0 base_velocity command -> ParallelismReferenceManager（reset 或每 24 帧重新规划） -> policy observation 中的当前 reference frame -> policy action -> 真实物理 Go2 -> 可视化实际状态、reference 状态与逐项 termination

速度 command 是 root/body 坐标系速度。面板值每个 control step 写入 env0 的 base_velocity；policy 和 planner 因此读取同一份 command。planner 仅在周期边界采用新 command，保证一个 24 帧计划内 command 不变，符合训练语义。

每次环境 reset 以及 episode frame 计数跨入新的 24 帧周期时，manager 使用当前真实 root、joint、foot 与 raycaster 高程/语义图生成新的 plan。回放不复用 extension/viz/go2_foostep_planner.py 的运动学直接写回逻辑。

3. 双 Go2 关节参考显示

真实 Go2 是场景原 robot，由 policy action 与物理仿真驱动，保持官方默认 mesh 和材质。

新增 reference Go2 articulation，使用相同 Go2 USD，关闭其全部 collision，且不参与控制、奖励、观测和 contact sensor。它与真实 Go2 完全重叠，不使用空间偏移；材质替换为半透明青绿色，以便从每个 hip、thigh、calf 和 foot 的外形直接比较当前 12 个 reference joint angle 与实际 joint angle。

每个 control step，reference articulation 写入 manager.current_root_pos_w、由 current RPY 构造的 root orientation、以及 manager.current_joint_pos。root/joint 顺序必须沿用 manager 已有的 planner-to-robot 映射，不能假设 USD DOF 顺序与 planner 顺序相同。

这个设计参考 InstinctLab motion-reference 的做法：reference articulation 仅作可视化，marker 与 reference robot 均由同一 reference frame 数据更新。

4. Parallelism 规划 marker

在 reference Go2 之外，复用 Parallelism viewer 已验证的 marker 视觉语言，但数据源改为 manager 的 24 帧缓存：

marker数据用途
未来 root trajectoryroot_pos_w[0, phase:]显示当前周期剩余 root reference。
四足 future swingfoot_pos_w[0, phase:, leg]显示每条腿当前及后续足端轨迹。
touchdown每条腿该周期的接触转换/目标足端明确落脚目标。
actual-reference foot error line真实 foot world pose 到当前 reference foot world pose区分 policy 跟踪误差与 planner 轨迹问题。

候选圆、候选点、surface collision points 不是本次必需项，仍由独立 planner viewer 用于 planner 调试，避免 RL rollout 画面过载。

5. Isaac Sim 面板

面板是 app 内 ImGui 窗口，不依赖 terminal 键盘。它只控制 env0，play 默认 --num_envs 1。

控件范围/默认行为
vx[-1.0, 1.0] m/s，默认 0写入 body-frame forward command。
vy[-0.5, 0.5] m/s，默认 0写入 body-frame lateral command。
vyaw[-1.0, 1.0] rad/s，默认 0写入 body-frame yaw-rate command。
全部不终止默认勾选批量勾选或取消下列逐项开关。
逐项 不终止默认全部勾选每一项仍计算并显示触发状态；勾选表示该项不参与 done/reset。

逐项开关固定为：time_out、base_contact、bad_orientation、parallelism_ref_root_z_too_far、parallelism_ref_projected_gravity_too_far、parallelism_ref_foot_z_too_far 和 parallelism_ref_joint_pos_too_far。

6. Termination 精确语义

面板始终显示每项的原始触发结果。本 step 触发时对应行高亮，即使它的 不终止 开关已勾选。这样可以连续观察“本应因 joint error 终止”的状态，而不丢失诊断事实。

屏蔽必须发生在 IsaacLab 消费 termination 结果并执行 reset 之前。不能在 env.step() 返回后再修改 dones，因为自动 reset 可能已经完成，画面已无法保留失败状态。

最终 done 是所有未勾选“不终止”的原始 termination 的逻辑或。勾选全部不终止后，所有项只诊断、不 reset；用户可关闭某一个开关恢复该项正常 reset。训练时的 termination 配置及训练脚本完全不变。

7. 文件与接口

文件职责
Go2Pvcnn/scripts/play.py新增 experiment 映射、Parallelism manager 获取、panel 生命周期、reference articulation 和 marker 更新、termination runtime mask。
tracking/parallelism_tracking_env_cfg.py仅在需要时补充 play-only reference visual articulation 配置；不改变训练 cfg。
tracking/register_envs.py若 play task id 必须独立注册，注册只指向 PLAY cfg 的 task；否则沿用现有 task id 并显式传入 PLAY cfg。
tests/tracking/...覆盖 experiment 映射、panel command 写入、reference frame joint/root 读取、逐项 termination mask 语义。

不复制 InstinctLab 源码，不修改 raw/，也不把 planner 的纯 kinematic playback 混入 RL 物理 rollout。

8. 验收

  1. 静态/单元测试确认 parallelism_tracking_flat 能从 play.py 解析、加载对应 checkpoint，且 manager 的 planner/robot joint reorder 保持正确。
  2. 真实 IsaacLab 非 headless 单环境启动，面板可调整三轴速度；policy command 与 manager command 在每个 control step 相等。
  3. reference Go2 与真实 Go2 重叠出现，reference 为青绿色无碰撞模型；随 phase 改变，12 个关节与 root pose 连续更新。
  4. 未来 root/foot/touchdown marker 与 manager 当前周期缓存一致；真实 foot 到参考 foot 的误差线随 policy 状态改变。
  5. 逐项触发 termination 时面板高亮。勾选该项“不终止”后不 reset；取消勾选后恢复正常 reset。验证至少 parallelism_ref_joint_pos_too_far 与一个非 reference termination。
