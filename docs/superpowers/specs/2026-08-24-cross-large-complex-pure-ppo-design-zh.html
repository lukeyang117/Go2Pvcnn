Cross Large Complex 纯 PPO 对照训练

目标：尽量保持当前 distillation 任务不变，只移除 teacher、imitation 与 Parallelism planner/reference，验证纯 PPO 的学习能力和 rollout 性能。

核心决定

新增独立实验 cross_large_complex_ppo，从零初始化 PPO + ActorCriticCNN。环境使用普通 ManagerBasedRLEnv，不创建 teacher，不加载旧 checkpoint，不挂载 reference manager，不执行 Parallelism 重规划。地形、命令、学生观测、locomotion rewards、课程和 PPO 参数尽量与当前 distillation 对齐。

一、实验问题与边界

本实验回答的问题

  • 没有 teacher action 和 imitation loss 时，当前 observation 与 locomotion rewards 能否让 policy 学会移动和复杂地形行走。
  • 移除每 23 个控制步执行的 Parallelism 重规划后，1024/4096 环境 rollout collection 能加速多少。
  • 当前地形课程无法上升的问题，是否主要来自 distillation/teacher 干扰，还是来自 PPO 奖励与课程本身。

明确不做

  • 不加载 teacher、student、critic、optimizer 或旧训练 checkpoint。
  • 不引入新的步态状态机、touchdown 事件或小障碍物落足塑形。
  • 不修改现有 ParallelismTrackingEnv、旧碰撞奖励和 distillation 算法。
  • 不修改地形课程的起终点净位移公式。
  • 不为了兼容本实验改动其他 teacher、distillation 或 Parallelism PPO 的网络结构。
对照原则

新实验与 run parallelism_tracking_cross_large_complex_distillation/2026-08-23_20-18-55/587d983 对齐。该 run 的 active_swing_foot_on_small_obstacle 实际为 null，所以新实验也不增加对应正奖励。

二、目标架构

普通环境ManagerBasedRLEnv
混合地形、语义扫描与物理仿真。
Actor学生同款非特权观测，输出带 std 的 12 维动作。
Critic独立特权观测，额外读取真实 base_lin_vel。

彻底关闭 Parallelism 的结构保证

  • 新 EnvCfg 直接继承普通 IsaacLab/Go2Pvcnn 基础 EnvCfg，不继承 ParallelismTrackingCrossLargeComplexEnvCfg 或 distillation EnvCfg；只复用 terrain factory 和语义布局配置。
  • Gym entry point 使用普通 ManagerBasedRLEnv，不是 tracking.env:ParallelismTrackingEnv。
  • 实验名不加入 trajectory manager 的启用名单。
  • 环境配置显式设置 planner_owned_reference_cache=False 和 use_batched_reference_trajectory=False。
  • 观测、奖励、termination 和 metrics 均不调用 get_parallelism_reference_manager。
  • 训练日志不得出现 [Planner] Attached。

PLAY 配置同样使用普通单环境 scene，只把 num_envs 改为 1 并关闭 observation corruption；不得使用带蓝色 reference robot 的 ParallelismTrackingPlaySceneCfg。

新实现的 policy 几何碰撞奖励

RewardTerm 名称继续使用 parallelism_geometry_collision，以便 TensorBoard 与旧 run 直接比较；函数替换为新模块中的 policy_geometry_collision_penalty，权重保持 -10.0。

live robot root_pos_w + root_quat_w + joint_pos
  └─> quaternion to root RPY
      └─> fk_go2(..., capsule_samples)
          └─> semantic_height_scanner 构造 ParallelismTerrain
              └─> official_collision_mask
                  └─> any(thigh/calf/foot collision over four legs)
                      └─> float collision event [num_envs]

函数返回非负二值事件，由 RewardTerm 的负权重施加惩罚，避免再次出现奖励符号翻转。它只复用静态 FK、碰撞形状与高程查询内核，不导入 reference manager，也不启动 planner。

允许的最小差异

旧 reward 依赖 planner 的 contact phase，只检查被视为 active 的腿。纯 PPO 没有该相位，因此新函数检查四条腿全部几何体。这是移除 Parallelism 后不可避免且明确记录的差异。

线速度课程

地形课程

继续使用 terrain_levels_vel_semantic_plane_gate，并保留当前 IsaacLab/Go2Pvcnn 判据：

distance = norm(root_xy_at_end - env_origin_xy)
move_up   = distance > terrain_tile_length / 2
move_down = distance < norm(command_xy) * episode_length_s * 0.5
move_down = move_down and not move_up

flat_dense_small_obstacles 仍排除在地形等级课程之外。本实验不修复转弯导致净位移偏小的问题，避免改变对照变量。

十一、成功标准与后续判断

本次实现成功不要求 4 iterations 内学会走路；4 iterations 只验证真实训练链路。正式训练后按以下结果判断：

观察结果结论
collection 明显变快，policy 能逐步移动和升级地形Parallelism/teacher 是主要额外开销，纯 PPO 路径可继续训练。
collection 变快，但仍长期站立问题主要在 reward、command 或 exploration，不是 teacher imitation。
速度课程上升但肉眼不移动继续检查速度 reward 统计和 standing command 混合，不修改 planner。
