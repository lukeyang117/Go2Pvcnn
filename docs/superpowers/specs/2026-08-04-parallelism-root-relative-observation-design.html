Parallelism Root 相对参考观测设计

将 RL policy 的 root reference 从“参考速度”改为“下一帧相对 root 位置和相对 root 姿态”，对齐 Instinct Lab 的当前机器人坐标系设计。

1. 目标与范围

  • policy 在当前时刻 t 执行动作。
  • policy 观察 Parallelism 轨迹的下一帧 t+1。
  • 所有 root reference 都相对于当前 IsaacLab 中 policy Go2 的真实 root。
  • 保持两个 root reference 槽位各 3 维，因此 actor、critic 输入总维度不变。
  • 不修改 Parallelism 的规划算法、root 规划轨迹、swing 轨迹和重规划逻辑。
  • 不修改现有 reward、termination、curriculum 的具体计算公式；tracking metric 改为记录 root 相对位置和相对姿态误差。

2. Instinct Lab 对齐原则

Instinct Lab 的 reference root 不是直接输入绝对世界位置。位置使用相对当前机器人 root 的量，姿态使用当前机器人 root 与 reference root 的相对旋转；当前机器人的速度和重力方向仍在当前 base frame 中表达。

内容Instinct Lab 做法Parallelism 采用的对应做法
reference 位置reference position 相对 robot anchorreference root position 减当前 policy root position，再转到 policy root frame
reference 姿态reference quaternion 相对当前 robot quaternionq_policy^-1 * q_reference 转成 3 维 axis-angle
当前 proprioception当前 root 的 angular velocity、projected gravity 等保留当前项目已有 proprioception

3. 新的 observation 定义

3.1 Root 相对位置

定义新 term：parallelism_ref_root_pos_b_t。

delta_pos_w = reference_root_pos_w[t + 1] - policy_root_pos_w[t]
ref_root_pos_b = quat_rotate_inverse(policy_root_quat_w[t], delta_pos_w)

输出顺序为 (x, y, z)，坐标系是当前 policy root 坐标系。它表达“当前机器人还需要向自身前、左、上哪个方向移动多少”。

3.2 Root 相对姿态

定义新 term：parallelism_ref_root_rot_b_t。

q_relative = quat_mul(quat_inverse(policy_root_quat_w[t]), reference_root_quat_w[t + 1])
ref_root_rot_b = axis_angle_from_quat(q_relative)

输出为 3 维 axis-angle。它表达 reference 相对于当前 policy root 的 roll、pitch、yaw 旋转误差。

不使用 6 维 tangent-normal，避免 actor/critic 输入维度增加，也避免已有网络结构因 observation 维度变化而无法加载。

4. 时间边界

情况reference 输入
普通执行当前真实状态为 t，输入轨迹 t+1
轨迹到最后一帧位置和姿态都钳制到最后一帧，直到重规划
重规划完成新轨迹第 0 帧对齐当前真实状态；policy 下一次输入新轨迹第 1 帧
重规划失败并进入 standstill保持现有 standstill 行为，不生成新的 reference 目标

因此不会出现读取 t+1 超出 24 帧的问题。索引访问统一使用 min(t + 1, horizon - 1)。

5. 维度和接口兼容性

旧字段新字段维度
parallelism_ref_root_lin_velparallelism_ref_root_pos_b3
parallelism_ref_root_ang_velparallelism_ref_root_rot_b3

root reference 总维度仍为 6，actor 和 critic 的总 observation 维度不变。语义字段名需要同步更新，避免继续把位置和姿态误认为速度。

6. 不在本次修改的内容

  • 不改变 Parallelism planner 的 root 预测方式。
  • 不把 root position 规划改成新的轨迹。
  • 不修改 joint reference、foot reference 或地图 observation。
  • 删除原 root velocity reward；Parallelism manager 内部速度差分接口不在本次删除范围内。
  • 不修改 termination 和 curriculum 的阈值及公式。

7. Tracking metric

对外输出的 root tracking metric 与新的 observation 语义一致：

  • Episode_Tracking/episode_reference_root_pos_error：当前 policy root 与下一帧 reference root 的相对位置误差范数，单位为米。
  • Episode_Tracking/episode_reference_root_rot_error：当前 policy root 与下一帧 reference root 的相对姿态 axis-angle 范数，单位为弧度。

RL 中删除原 root velocity reward；manager 内部速度差分仅保留给 Parallelism reference 接口使用。课程升级改用 root position/root rotation episode error 和 joint mean/max error，不再用速度误差作为升级条件。

8. 验证要求

  • 静态检查 observation term 名称、维度和 actor/critic 配置一致。
  • 用 policy root yaw 旋转的场景验证：reference 前进方向在 policy frame 中仍正确。
  • 用 root roll、pitch、yaw 非零的场景验证相对姿态 axis-angle 有限且方向正确。
  • 验证普通末帧、重规划成功、重规划失败三种边界不会索引越界。
  • 运行 tracking 相关单元测试，确认现有 planner 和 play 逻辑没有被改变。
