M1 Parallelism 小障碍与轮式滑行设计

在不改变 Go2 默认执行路径的前提下，让 M1 复用同一套规划接口：平地以轮式滚动为主，只有被最终选中的候选轨迹确实穿过小障碍时才触发单腿 swing；大障碍继续沿用绕行。

设计结论

50 / 腿每条腿固定生成 50 个候选落点
按轨迹候选点对应的整条 XY 轨迹单独判定 swing
12 DOF只规划 ABAD、HIP、KNEE，不关心轮轴关节
0.095958 mM1 轮半径进入 clearance 和碰撞包络

一句话规则

候选点先通过可达性、落地高度和碰撞验证；之后只读取最终选中候选的 needs_swing。选中且为真才 swing，选中且为假就保持当前腿角随 Root 滚动，其他候选和其他腿互不影响。

边界与不变项

Go2 默认行为不变不传 --robot 时仍使用 Go2 backend、Go2 FK/IK、Go2 配置和原有规划行为。
统一规划接口候选生成、Root rollout、评分、fallback、轨迹输出结构继续由通用 Parallelism 使用。
M1 独立几何M1 单独提供 USD 对齐参数、12/16 DOF 映射、解析 FK/IK、关节限位和碰撞 primitive。
轮轴默认不动四个 *_FOOT_JOINT 不作为 planner 输入或输出，也不参与关节限位和误差评分。
平地滑行flat 与 flatDense 的 Root 高度固定，正常情况下不主动抬轮。
非平地抬腿rough、坡面、台阶或小障碍地形可根据最终候选轨迹触发单腿 swing。
大障碍绕行大障碍不升级为普通 swing，继续使用当前侧向绕行和候选拒绝逻辑。
不检测 BASE与 Go2 当前边界一致，不新增 BASE 碰撞点和 link 间 self-collision。
不改 RLParallelism 只输出现有轨迹 schema；下游如何消费轨迹不在本设计范围。
先验证后固化viewer 的 slider 只是临时 override，确认后的参数才写入 M1 配置。
明确不做：重新设计 trot/rolling gait、让 Parallelism 规划轮子转速、修改 Go2 公式、接入训练流程或用统一的 M1/Go2 碰撞尺寸代替各自 USD 几何。

Candidate 层

  • 语义检查针对每一条“当前轮心到候选落点”的 XY 轨迹。
  • 碰撞检查继续检查整条 swing 过程的 M1 几何采样点。
  • 候选是否合法与候选是否需要 swing 是两个字段，不能互相替代。

Selected 层

  • 先按原有 score 选出每条腿的唯一候选。
  • 只有 selected candidate 的标记可以控制这条腿。
  • 未选中的候选即使穿过障碍，也不会使该腿 swing。

小障碍的单腿 swing 规则

本设计把“是否需要抬腿”和“是否发生碰撞”分成两层。语义层负责识别某条候选轨迹是否经过小障碍，几何层负责确认生成的腿部和轮子形状是否真的安全。

候选轨迹定义

for leg in {FL, FR, RL, RR}: for candidate in 50 candidates: xy_path = interpolate(current_wheel_center.xy, candidate_foot.xy, path_samples) path_has_small_obstacle[leg, candidate] = any(semantic(xy_path) == SMALL_OBSTACLE) needs_swing[leg, candidate] = path_has_small_obstacle[leg, candidate] or terrain_profile_requires_swing selected = argmin(valid_score, dim=candidate) leg_swing = needs_swing.gather(candidate=selected)
阶段输入输出约束
候选生成当前轮心、命令、候选半径candidate_w[B,4,50,3]四条腿独立，固定 50 个点
轨迹语义当前轮心 XY、候选 XY、semantic mapneeds_swing[B,4,50]检查整条路径，不只检查端点
候选验证Root rollout、M1 FK/IK、terraincandidate_valid[B,4,50]不可达、越限、碰撞、落点非法均拒绝
选择后执行selected_index[B,4]leg_swing[B,4]只读取选中项，不回看落选项

执行分支

leg_swing == true

该腿使用当前轮心到 selected foothold 的 XY 轨迹，并按照局部地形最高值加轮子包络和 clearance 生成 Z apex。落地后回到 selected foothold。

leg_swing == false

该腿保持当前腿关节角或当前轮心相对 Root 的滚动关系，随 Root 前进，不额外制造摆腿高度。它不会被另一条腿的障碍轨迹联动。

关键区别：“语义轨迹命中小障碍”不是“碰撞检测已经通过”。前者仅产生 needs_swing；候选仍必须经过完整 M1 碰撞近似和落点验证。反过来，候选若最终没有被选中，也不会触发 swing。

大障碍处理

semantic ID 为 large obstacle 时，不设置普通 swing 标记；候选沿用现有大障碍绕行策略。若绕行候选仍全部无效，保持当前 standstill fallback，并保留 reject bits 供 viewer 诊断。

M1 USD 几何与安全包络

M1 的规划参考点是轮心，而不是轮子最低点。轮子圆盘的半径必须在高程和碰撞判断中显式补偿，否则小障碍会被候选拒绝，最终表现为 Root 不移动或 standstill。

r = 0.095958 m轮子半径
w = 0.04650 m轮子厚度
+0.003 m碰撞余量
0.1192 m半径加半厚度的水平保守范围

摆腿高度

local_max_height = max(heightmap over wheel projected footprint) wheel_envelope = wheel_radius_m + collision_margin_m swing_z = local_max_height + wheel_envelope + swing_extra_clearance_m M1 initial effective clearance ≈ 0.105 m flat / flatDense: no active swing by default, Root Z fixed

高程查询至少覆盖半径加半厚度的水平范围，约 0.1192 m；对于离散高程图，可使用局部窗口最大值。摆腿轨迹的 apex 不再只取中心线高程，必须包含轮子的垂向包络。最终碰撞检测仍保留，作为数值安全闸门。

对称碰撞 primitive

部件每腿数量近似形状采样用途
ABAD link1box26 个边界点腿上段碰撞
HIP link1box26 个边界点髋部连杆碰撞
KNEE link1box26 个边界点小腿碰撞
Wheel1绕 Y 轴 cylinder3 层 × 12 角 + 2 端面中心 = 38 点轮盘、侧面和轮底接触

四条腿共 16 个 primitive；每腿 116 个表面采样点，共 464 个点。不加入 BASE。左右腿通过符号对称生成，保留 M1 USD 的 link 尺寸和左右 ABAD 限位差异。

碰撞点判定

terrain_height(point.xy) >= point.world_z - collision_margin_m => collision ordinary terrain + wheel-bottom support point + contact => tolerate contact semantic obstacle hit, swing frame, wheel side/top/front hit => never tolerate
轮底规则：只有轮子圆周最低方向的三个宽度层采样点，可以在普通地形接触状态下被容忍；障碍物语义、摆动帧和轮子其他方向的点仍按碰撞处理。

解析 FK / IK 与站姿

M1 使用独立解析运动学，规划点是四个轮心。轮轴角度不参与 FK/IK；轮轴在 Isaac Sim 回放时保留当前值。

Root → BASE-to-ABAD translation → RotX(ABAD) → ABAD-to-HIP translation → RotY(HIP) → HIP-to-KNEE translation → RotY(KNEE) → KNEE-to-wheel-center translation

FK

  • 输入 Root pose 和 12 个腿关节。
  • 输出四轮心、髋、膝、小腿采样点和 wheel frame。
  • 碰撞 primitive 使用 FK 后的 link frame 转到世界坐标。

解析 IK

  • 输入 Root pose 和四个轮心目标。
  • 按 M1 的侧向偏移和两段长度解算 ABAD/HIP/KNEE。
  • 解析结果必须经过 joint limit、finite 和 FK residual 检查。
项目M1 设计值说明
planner 顺序FBL, FAR, RBL, RAR × ABAD/HIP/KNEE12 DOF；映射到 FL/FR/RL/RR
默认腿站姿ABAD = 0, HIP = -0.15, KNEE = 0.30 rad避免当前全零姿态过直
轮轴默认保持 USD / 当前状态不复制、不清零、不规划
平地 Root Z由默认站姿和轮半径计算当前约 0.6299 m，以 M1_ROOT_Z_M 为准，flat 固定
限位ABAD 左右不对称；HIP/KNEE 使用 M1 USD 对齐范围越限候选直接拒绝
Go2 隔离：Go2 的解析 FK/IK 和现有数值不搬入 M1 公式；planner 只依赖统一 backend 接口，因此 M1 分支不会改变 Go2 路径。

地形列、Root 高度与姿态

通过 terrain 的 subterrain column 选择 profile。Root 只在明确允许跟随地形的 family 中变化；flat 与 flatDense 保持由 M1_ROOT_Z_M 给出的固定高度，不因局部障碍把机身整体抬高。

地形列 / familyRoot ZRoot 姿态腿部策略
flat固定约 0.6299 m水平滚动为主，不主动 swing
flatDense / small obstacles固定水平只对最终选中且轨迹命中小障碍的腿 swing
random_rough跟随局部高程，低频滤波有限 roll/pitch按局部高程和语义决定
pyramid slope跟随地形趋势跟随坡度但限幅按坡面高程生成 swing
boxes / stairs跟随台面高度保持默认站姿趋势，避免追随离散法向大障碍绕行，小障碍可 swing

random_rough 与 box 的区别

random_rough 是连续或随机高程扰动，重点是 Root 高度和姿态的平滑跟随；box 是离散凸起障碍，重点是障碍语义、候选绕行和轮子几何是否越障。

未知 column

使用保守 profile 并记录诊断，不默认为 flat；这样新地形不会意外关闭 clearance 或 Root 跟随。

Isaac Sim Viewer 设计

Go2Pvcnn/extension/viz/go2_foostep_planner.py 根据 --robot 同时选择 USD、Isaac Lab 环境配置、backend、body selector 和 16 DOF 回放映射。调参面板仍参考 Go2，但初值来自当前机器人和 terrain profile。

模式资产 / 环境规划输出回放行为
--robot go2现有 Go2 USD 与 viewer 配置现有 Go2 轨迹保持原行为
--robot m1M1 USD 与 M1 viewer env cfg12 DOF 腿关节 + Root写入 16 DOF 腿关节，轮轴保留当前值

M1 逐帧回放

q16_next = q16_current.clone() q16_next[m1_leg_joint_indices] = q12_planned q16_next[m1_wheel_joint_indices] = q16_current[m1_wheel_joint_indices] write(root_pose_planned, q16_next)

Viewer 直接回放 Parallelism 规划的 Root 和腿关节，不接入 RL policy。轮轴既不被 planner 改写，也不作为 swing 的触发条件。显示内容包括 Root 轨迹、四轮心轨迹、候选圆、最终落点、semantic map、M1 collision points、selected index 和每个候选的 reject bits。

推荐启动形式

python Go2Pvcnn/extension/viz/go2_foostep_planner.py \ --planner-backend parallelism \ --robot m1 \ --terrain task \ --terrain-row 0 --terrain-col 0 \ --num-envs 1 --n-frames 30 --plan-dt 0.02

真实 Isaac Sim smoke 需要使用项目约定的 Isaac Sim Python、DISPLAY、CUDA 和 VirtualGL 环境。设计阶段不把具体机器上的动态库路径固化进代码。

面板调参：swing_clearance、candidate radius、semantic margin、Root follow 开关和显示开关都是本次 viewer 的 override；关闭 viewer 后不修改 Go2 或 M1 默认配置。

验证与验收

逻辑单元测试

  • 每腿候选 shape 固定为 [B,4,50]。
  • 单条 XY 轨迹命中小障碍时只标记对应 leg/candidate。
  • 落选候选的 needs_swing 不影响执行。
  • selected false 时腿保持 rolling，不生成 swing apex。

M1 几何测试

  • USD joint/body name 与映射顺序一致。
  • 默认站姿不再是全零导致的过直姿态。
  • 解析 IK → FK residual 在容差内。
  • 轮轴不进入 planner 输出，轮半径进入 clearance。

碰撞与回归测试

  • 16 shapes、464 surface points、无 BASE point。
  • 轮底普通接触可容忍，障碍接触不可容忍。
  • 小障碍 clearance 不足时可复现 reject/standstill。
  • 补偿后候选可通过并在 viewer 中跨越。
