Parallelism 蒸馏 Teacher 与 Critic 观测解耦

目标：使用 6def073 训练的新教师网络恢复蒸馏训练，同时完整保留旧 student actor 与 student critic，不让新教师增加的 3 维 command 输入破坏旧 critic。

核心决定

teacher 和 critic 不再共用同一份观测。新 teacher 使用 1102 维特权观测；student critic 继续使用旧的 1099 维特权观测。resume 时显式指定的 teacher checkpoint 始终覆盖 student checkpoint 内嵌的旧 teacher。

一、当前问题

当前蒸馏路径把同一个 teacher_obs 同时传给 frozen teacher 和 student critic：

teacher_obs
  ├── frozen teacher actor：生成 imitation target
  └── student_critic：生成 PPO value

6def073 给大型地形 teacher 的 state 增加了 velocity_commands，因此新教师输入从 1099 维变为 1102 维。若直接让 critic 也使用这份新观测，旧 model_5499.pt 的 critic 权重将无法直接加载。

实际上，critic 并不需要依赖新 teacher 的输入结构。它只需要一份稳定的 privileged observation 来估计 value，teacher actor 则需要新 command 才能复现新教师行为。

二、目标数据流

student MLP 输入 · 1069 维环境 flatten 后为 557 维；经过 CNN 后进入 student actor。学生不接收 reference trajectory。
teacher MLP 输入 · 1102 维环境 flatten 后为 590 维；包含新 command，输入 frozen teacher actor。
critic MLP 输入 · 1099 维环境 flatten 后为 587 维；使用旧版 privileged map/state，不加入新 command。
student_obs  ────────────────> student actor ──> student action
teacher_obs (1102) ─────────> teacher actor ──> teacher action target
critic_obs  (1099) ─────────> student_critic ─> PPO value

环境动作：按 teacher_ratio 选择 teacher action 或 student action
PPO value：始终使用 critic_obs
imitation loss：student mean 与 teacher action 比较

四、Checkpoint 加载顺序

  1. 创建新结构：student actor 输入 1069，teacher actor 输入 1102，student critic 输入 1099。
  2. 加载蒸馏 checkpoint model_5499.pt 的 student actor、student critic、student std 和 optimizer。
  3. 跳过该 checkpoint 中的 teacher.*，不使用旧 teacher。
  4. 加载显式路径指定的新 teacher model_4999.pt，只写入 frozen teacher 子网络。
  5. 保留 checkpoint 的 iteration 5499，继续从该 iteration 之后训练。
student checkpoint:
  student.*          加载
  student_critic.*   加载，维度仍为 1099
  teacher.*          跳过

explicit teacher checkpoint:
  actor.* / cnn.* / std  ──> 写入 StudentTeacherCNN.teacher
std 规则

resume 脚本保留 --keep_std，因此 student 使用 model_5499.pt 中保存的 std。新 teacher 使用 model_4999.pt 中的 teacher std；两者是不同网络的参数，不互相覆盖。

五、损失与环境动作

本设计不修改损失公式：

teacher_action = Teacher(teacher_obs)
student_mean   = Student(student_obs)
value          = StudentCritic(critic_obs)

imitation_loss = MSE(student_mean, teacher_action)
ppo_loss       = PPO(student action, value, rollout return)
total_loss     = ppo_coef * ppo_loss + teacher_coef * imitation_loss

每个 episode 的 teacher/student 接管来源仍然固定，避免同一个 episode 中途切换控制源。环境动作依旧由原有 teacher_ratio 决定；新 teacher 只是替换 teacher action 的来源。

六、Resume 命令语义

resume 脚本将明确包含以下两条路径：

--load_run 2026-08-18_21-38-36/6def073
--load_checkpoint model_5499.pt
--teacher_checkpoint /share/home/tm884089579940000/a915071960/lhy/kinematic/Go2Pvcnn/logs/rsl_rl/parallelism_tracking_cross_large_complex/2026-08-18_20-30-59/6def073/model_4999.pt

规则是：--load_checkpoint 指向 student resume 权重，--teacher_checkpoint 指向 frozen teacher 权重。只要显式提供 teacher 路径，就绝不从 student checkpoint 恢复旧 teacher。

七、验证方案

静态与单元测试

  • 检查 CNN 后 MLP 输入维度为 teacher 1102、critic 1099、student 1069；对应环境 flatten 维度为 590、587、557。
  • 构造两个独立观测输入，确认 teacher action 使用 teacher obs，value 使用 critic obs。
  • 加载旧 student checkpoint 后，确认 student actor 与 student critic 权重成功恢复。
  • 显式加载新 teacher 后，确认 teacher actor 第一层权重来自 model_4999.pt，而不是 model_5499.pt。
  • 运行现有 tracking 测试集，确认普通 PPO 和旧 teacher 训练路径不受影响。

1024 环境启动测试

  • 使用新的 resume 脚本启动 1024 环境。
  • 至少完成 4 个 iteration，不出现矩阵维度错误或 checkpoint 加载错误。
  • 启动日志打印 student checkpoint、teacher checkpoint、teacher obs 维度、critic obs 维度。
  • 确认 TensorBoard 的 PPO、imitation、teacher action share 和 episode 指标继续产生。

八、明确不修改的部分

  • 不修改 Parallelism 规划、reset、重规划周期和 reference 轨迹。
  • 不修改 reward、termination、curriculum 和 small/large obstacle 场景。
  • 不把 velocity command 加回 student 输入；student 仍只按当前 distillation 配置输入速度指令，不输入 reference trajectory。
  • 不删除旧 critic，不重新随机初始化旧 critic。
  • 不改变 teacher_ratio 的 episode 级固定接管逻辑。
