1. 目标、验收顺序与设计边界

必须实现

  • 小障碍不得踩踏或碰撞，摆动足和整条腿从上方连续跨过。
  • 大障碍不得跨越，落脚候选和身体轨迹从其膨胀占用区外绕行。
  • 支撑足世界坐标贴地且不滑；root 运动由支撑腿关节补偿。
  • 速度命令在当前可修改的 touchdown 事件上立即生效。
  • 低速或平缓地形时保持 reset 时的 root 姿态和关节姿态。
  • root z、roll、pitch 可为净空与可达性小幅变化，但受绝对量和变化率限制。
  • 同一实现支持 viewer 的单环境诊断和 1024 个 RL 环境的固定形状批处理。

明确不做

  • 不优化接触力、力矩、质心动力学、惯量或刚体动力学状态。
  • 不在线改变 trot 的腿序、12/12 接触时长或 gait topology。
  • 不把普通全身碰撞 soft loss 当作安全机制。
  • 不使用多个离散四足组合；每条腿只在自己的预测 hip 坐标系独立选点。
  • 不做迭代式 apex 加高，不在 line search 内重新选择 touchdown。
  • 无安全候选时不发布“最不坏”的碰撞轨迹；输出明确 stop/invalid。

1.1 严格验收顺序

Gate 0: 数学、shape、FK/IK/Jacobian、scanner parity、scan/dense parity
  -> Gate 1: flat 的 M_common 全部指标 + actual viewer
  -> Gate 2: small 的 M_common 全部指标 + M_small + actual viewer
  -> Gate 3: large obstacle bypass 全部适用指标 + actual viewer
  -> Gate 4: 1024 x 1000 性能门和 RL batch regression
M_common = {joint, execution tracking, foot continuity, stance, swing,
            command response, root tracking/posture, all-part collision,
            RTI/line-search, numerical, map, warm lifecycle}
M_small  = {strict crossing, cross clearance/denominator,
            touchdown/stance on small, small-event collision}

Pass_flat  = AND_(m in M_common) Pass(flat,m)
Pass_small = AND_(m in M_common union M_small) Pass(small,m)

Gate 1 没有全部通过时，不允许用 small 参数掩盖平地问题；Gate 2 必须在 small obstacle 场景重新运行并通过 M_common 的每一个指标，不能只看 crossing success。任一 common 指标在 small 中回归，small 整体即失败。Cross 在没有障碍的 flat 上不存在物理分母，因此不伪造“零事件通过”，而是在 M_small 中追加。测试可以按 gate 推进，但生产架构从第一次实现起就是本文定义的完整架构，不建立另一套临时 planner。

2. 固定状态、时间与运行合同

dt = 0.02 s
horizon_steps = 30
state_nodes = 31
prediction_time = 0.60 s
gait_period = 24 frames = 0.48 s
swing_steps = 12
stance_steps = 12
gait = diagonal trot
sqp_iterations_per_refresh = 1
lq_qp_subproblems_per_refresh = 1
line_search_alphas = [1, 0.5, 0.25, 0.125, 0]

节点状态固定为：

z_k = [p_B,k, theta_B,k, q_k] in R^18
p_B,k     = [x_B,k, y_B,k, z_B,k]
theta_B,k = [roll_B,k, pitch_B,k, yaw_B,k]
q_k       = 12 个 Go2 关节角
Z         = [z_0, ..., z_30] in R^(31 x 18)
  • z_0 是当前 measured state，严格注入，不是可自由改变的动作。
  • z_1 是本周期准备发布的下一时刻状态；完整 z_1...z_30 是供下一轮 warm shift 和 RL teacher 使用的预测。
  • 足端、膝、calf、thigh、hip 和 base 几何均由 FK(z_k) 得到，不增加独立足端优化变量。
  • 所有 batch 张量以环境维 B 开头；正式运行固定支持 B=1 和 B=1024 的编译图。
  • gait phase、地图尺寸、候选数、碰撞布局、H30/32 scan 树和五个 alpha 在图捕获前固定。
纯运动学硬边界：优化变量只有 root pose 和 12 个关节角。速度、加速度仅由相邻 pose/关节角做有限差分；不建立质量、惯量、接触力、冲量、力矩、动量、刚体动力学或接触动力学方程。碰撞检测只使用 FK 几何和语义/高程图，不读取 Isaac contact sensor。

3. 单次 RTI 完整流程

输入同帧 measured z0、command、gait phase、elevation、semantic、T_WG、warm cache
  1. scanner field build：统一 2.5D 安全场与 max_pool2d 膨胀层
  2. warm shift/rebase：上一轮选中轨迹向前滚动并对齐 measured z0
  3. perceptive preview：large 左/右 body corridor + 四腿下一次 touchdown event
  4. touchdown selector：每腿 25 个 hip-frame 候选，GPU 并行筛选与评分
  5. convex region builder：围绕每个选中点构造安全矩形与局部平面
  6. nominal retarget：生成连续 swing、stance anchor 和 batched IK nominal
  7. one SQP linearization：残差、FK Jacobian、碰撞与约束线性化
  8. one LQ/QP：H30/32 associative scan 求 Delta Z
  9. five-alpha line search：并行真实代价 + 全时域 swept hard safety
 10. publish/cache：只发布安全候选 z1；缓存完整选中轨迹与 touchdown event
输出 trajectory、region、candidate masks、stop mask、metrics diagnostics
职责分界：touchdown selector 决定“落在哪里”；convex region 决定“LQ 可以在多大范围内连续调整”；nominal 决定“从当前脚状态怎样连续走向该区域”；LQ 决定 root 与关节如何协同；line search 决定这次修正是否在真实非线性几何下可以发布。

4. Scanner 与统一 2.5D 安全场

4.1 输入和坐标合同

延续真实 scanner 的局部地图合同：每环境 151 x 151、分辨率 r_map=0.01m，地图原点和朝向随当前 measured root 更新。碰撞几何始终在世界坐标系构造，再用当前帧唯一的 world-to-grid 变换查询；地图外和 scanner unknown 均视为不安全。

H[b,x,y]       : elevation height
S[b,x,y]       : semantic id
V[b,x,y]       : scanner valid mask
T_WG,t         : current grid-to-world transform
T_GW,t         = inverse(T_WG,t)
M_s            = 1[S in small_ids]
M_l            = 1[S in large_ids]
M_u            = 1 - V
M_forbidden    = M_l OR M_u

g_t(p_W) = project_xy(T_GW,t [p_W;1])
query_t(p_W) = bilinear(F_t,g_t(p_W))

4.1.1 同帧 freshness 合同

refresh_id(H_t) = refresh_id(S_t) = refresh_id(V_t)
                = refresh_id(T_WG,t) = refresh_id(z_measured,t) = t
max_field_age_steps = 0
map_age_frames = t-refresh_id(F_t) = 0
map_state_timestamp_error = |timestamp_map-timestamp_state| = 0
  • 每次 RTI 都从本 refresh 的 H_t/S_t/V_t/T_WG,t 重建 F_t；禁止读取 F_(t-1) 或更早的语义/高程 field。
  • 预分配和 CUDA Graph 可以复用内存地址，但 replay 前必须在正确 CUDA stream 完成本帧地图内容和 metadata 覆盖；“复用 buffer”不等于复用上一帧数据。
  • 当前 scanner 未更新、frame id 不一致、时间戳不一致或 world/grid transform 不匹配时，该环境立即 stop=true，不得用缓存 field 继续规划。
  • warm trajectory、latched touchdown 和 persistent anchor 可以跨帧保存，但每轮必须全部重新投影到世界坐标并用 F_t 验证；它们不能携带旧地图的 safety 结论。

统一地图不是把所有信息压成一个标量，也不是三维体素。它是固定通道的 2.5D tensor：

F = [H, V, M_s, M_l, M_u,
     H_r for each geometry radius,
     landing-safe masks,
     slope_x, slope_y, roughness,
     semantic boundary masks]

这使 touchdown、LQ 和 line search 使用同一份地图语义，同时保留“small 可跨但不可踩”和“large 必须绕行”的差异。

4.2 max_pool2d 膨胀和半径高程

对物理半径 r 与安全余量 m，固定 kernel 半径为：

n_r = ceil((r + m) / r_map)
k_r = 2 n_r + 1
D_r(M) = max_pool2d(M, kernel=k_r, stride=1, padding=n_r)

碰撞查询使用半径膨胀高程：

H_eff,c(x,y) =
  H(x,y)                         normal / small for swing
  h_wall                         large or unknown

H_r,c(x,y) = max_pool2d(H_eff,c, kernel=k_r, stride=1, padding=n_r)
d_c(p) = p_z - H_r,c(p_x,p_y)

H_r,c 为 foot、calf、thigh 和 base 分别构建。max_pool2d 同时处理 [B,C,151,151]，禁止按环境、部位或像素循环。large/unknown 使用足够高的 h_wall，small 对 swing 保留真实物高，对 touchdown mask 则直接膨胀为 forbidden。

4.3 Landing、边缘与局部平面字段

M_land_forbid = D_(r_sole + m_land)(M_s OR M_l OR M_u)
g_x, g_y      = fixed Scharr(H)
slope         = atan(sqrt(g_x^2 + g_y^2))
roughness     = max_pool2d(H) - min_pool2d(H)
M_edge        = 1[slope > slope_max OR roughness > roughness_max]
M_land_safe   = NOT (M_land_forbid OR D_edge(M_edge))

min_pool2d(H)=-max_pool2d(-H)。Touchdown detector 和最终碰撞 detector 始终读取原始语义、原始高程和真实几何；模糊或膨胀场只能更保守，不能让验收标准变宽。

4.4 Large-only body corridor preview

只靠 foot touchdown 不能保证 base 绕开 large。若 command/warm root centerline 与 base-radius 膨胀的 large mask 相交，使用固定左右两个 corridor hypothesis；small 不触发该逻辑：

e_cmd  = normalize(v_cmd,xy)
e_perp = [-e_cmd,y,e_cmd,x]
d_left  = e_perp^T(p_large,left-edge-p_B,command) + r_base + m_base + d_bypass,buffer
d_right = e_perp^T(p_large,right-edge-p_B,command) - r_base - m_base - d_bypass,buffer
d_side in {d_left,d_right}

p_B,side,xy(k) = p_B,command,xy(k) + b(xi_k)d_side e_perp
S(u) = 10u^3-15u^4+6u^5
xi_enter(k) = clamp((s_k-(s_in-L_enter))/L_enter,0,1)
xi_exit(k)  = clamp(((s_out+L_exit)-s_k)/L_exit,0,1)
b(xi_k) = S(xi_enter(k))S(xi_exit(k))    smooth enter, hold and return

valid_side = all base OBB samples/intervals outside D_(r_base)(M_l OR M_u)
J_side = w_length path_length + w_offset sum_k |b(xi_k)d_side|^2
       + w_switch 1[side differs from latched side]

选择代价最低的 valid side，并在 base 完全通过 large 之前 latch；两侧都无效则 stop。它只有左右两个固定 body reference，不枚举四足组合，也不替代 LQ。选中的 p_B,corridor 用于 hip touchdown pose 预测、large 场景的 root nominal 和 root corridor cost；四条腿仍各自在自己的 25 点网格独立选择。该顺序保证 feet 与 body 使用同一个绕行侧，不会出现前腿向左、后腿向右的相互拉扯。

5. 每轮 touchdown 选择

5.1 事件时间与 hip 预测

对腿 i，由固定 gait schedule 计算下一次 swing -> stance 事件：

stance_i(k) = 1[phase_i(k) in stance interval]
n_td,i = min {n >= 1 | NOT stance_i(n-1) AND stance_i(n)}
t_td,i = n_td,i dt

n_td,i 在一个 gait period 内闭式求出，不截断到 30。若 n_td,i > 30，事件仍保存时间、目标、区域和 preview tail。root/hip 预测优先使用第 4.4 节选中的 large corridor；没有 large encounter 时使用 shifted warm root 与 command 尾部外推：

p_B^pred(k) = p_B^corridor(k) if large corridor is active
p_B^pred(k) = p_B^warm(k),                                  k <= 30 otherwise
p_B^pred(k) = p_B^warm(30) + R_z(yaw_30)v_cmd,xy dt(k-30), k > 30
yaw^pred(k) = yaw^warm(k) or yaw_30 + omega_cmd dt(k-30)
p_H,i^pred  = p_B^pred(n_td,i) + R_B^pred p_H,i(q_ref)

每条腿在自己的预测 hip yaw frame 中搜索，四条腿没有组合候选集，也没有 25^4 枚举。

5.2 固定候选网格

Delta_ab = [d_x[a], d_y[b]],  a,b in {0,...,4}
p_ab,xy = p_H,i,xy^pred + R_z(yaw_H,i^pred) Delta_ab
N_candidate = 5 x 5 = 25 per leg

候选必须同时满足：

valid_land     : complete sole lies in M_land_safe
valid_reach    : q_IK(p_ab) lies inside joint safe bounds and workspace margin
valid_plane    : slope, roughness and plane residual pass
valid_semantic : no small, large, unknown or map-boundary overlap
valid_swing    : deterministic foot/calf/thigh/knee sweep is collision-free
valid_ab       = AND of all conditions

5.3 小障碍跨越条件

命令平移非零时：

e_cmd = v_cmd,xy / max(||v_cmd,xy||, epsilon)
s(p)  = e_cmd^T (p_xy - p_lift,xy)

若 lift-to-candidate 走廊与 small footprint 相交，该候选只能在障碍后方落地：

s_obs,out = max {s(x) | x belongs to inflated small footprint in the corridor}
s(p_td) >= s_obs,out + d_landing
M_s(p_td sole) = 0

这里“后方”是沿当前 e_cmd 从 lift point 看越过障碍的一侧，不是固定世界 x 正方向。若候选虽然位于后方但整腿 sweep 不安全，它仍被排除；跨越条件不是对安全条件的替代。

5.4 大障碍绕行条件

large 的 D_r(M_l) 对 foot 和全部 link 均是 forbidden。候选评分允许向左右绕开，但任何候选和其 sweep 都不得穿过 large 膨胀区：

valid_large = 1[Gamma_foot, Gamma_calf, Gamma_thigh do not intersect D_r(M_l)]
J_bypass(p) = w_progress ||p - p_cmd||^2
            + w_lateral ||e_perp^T(p - p_hip)||^2
            + w_switch ||p - p_td,previous||^2

左右两侧分数相同时，使用腿固定外侧方向和稳定 index 做确定性 tie-break，防止每轮左右抖动。

5.5 连续 swing 和一次 apex 计算

对每个 landing-safe 候选，先定义固定外侧向量 n_i 和水平路径：

S(tau) = 10 tau^3 - 15 tau^4 + 6 tau^5
B(tau) = 64 tau^3 (1-tau)^3
p_xy(tau) = p_lift,xy + S(tau)(p_td,xy - p_lift,xy)
          + B(tau) delta_out n_i
p_apex,xy = (p_lift,xy + p_td,xy)/2 + delta_out n_i

沿该走廊一次查询最大有效高度：

z_apex = max_(x in Gamma) H_(r_foot)(x) + r_foot + m_z

不重复加高 apex。z 使用两段零速度/零加速度 smoothstep：

z(tau) = z_lift + S(2tau)(z_apex-z_lift),          0 <= tau <= 0.5
z(tau) = z_apex + S(2tau-1)(z_td-z_apex),         0.5 < tau <= 1

固定 preview 样本和相邻样本的保守 segment bound 检查 foot sphere、calf/thigh capsule 与 knee endpoint。只有完整 sweep 通过的候选才能参与评分。

5.6 评分、选中与 latch

p_cmd = p_H,i^pred + R_z(yaw_H,i^pred)p_nominal_step(v_cmd,omega_cmd)
J_td(ab) = w_cmd_td ||p_ab-p_cmd||^2
         + w_warm_td ||p_ab-p_td,previous||^2
         + w_slope slope_ab^2
         + w_rough roughness_ab^2
         + w_edge / max(distance_to_forbidden_ab,epsilon)
         + w_out delta_out_ab^2

score_ab = J_td(ab) if valid_ab else +infinity
p_td,target = candidate[argmin(score)]
  • future stance 和 swing 前半段每轮允许重选，w_warm_td 保证变化连续。
  • swing 后半段锁定已选 region，不因小的评分变化换点。
  • 锁定 region 一旦因新地图变得不安全，当前周期立即失效；重新搜索仍无安全点则输出 stop。
  • touchdown selector 每轮都运行；“运行”不等于每轮都切换目标。

6. Touchdown 凸区域

6.1 Hip-aligned 安全矩形

selector 输出中心 c_i=p_td,target。region builder 在完整 sole-safe mask 内，沿预测 hip frame 的正负 x/y 方向计算离最近 forbidden cell 的保守距离：

u = R_H,i,xy^T (p_xy-c_i)
l_x^- = min(d_x^-,l_x,cap)-m_region
l_x^+ = min(d_x^+,l_x,cap)-m_region
l_y^- = min(d_y^-,l_y,cap)-m_region
l_y^+ = min(d_y^+,l_y,cap)-m_region

矩形内部所有栅格及完整 sole footprint 必须属于 M_land_safe。约束写成：

-l_x^- <= u_x <= l_x^+
-l_y^- <= u_y <= l_y^+

A_td p_xy + b_td >= 0
A_td = [ r_x^T; -r_x^T; r_y^T; -r_y^T ]
b_td = [ l_x^- - r_x^T c;
         l_x^+ + r_x^T c;
         l_y^- - r_y^T c;
         l_y^+ + r_y^T c ]

任一半边长度小于 l_region,min 时，该中心候选被拒绝并选择下一安全候选；region builder 不把矩形扩入障碍以换取面积。

6.2 局部地形平面

在矩形内对 valid、normal-ground cells 做固定形状加权最小二乘：

h_plane(x,y) = h(c) + h_x(c)(x-c_x) + h_y(c)(y-c_y)
rho_plane = max_(x in region) |H(x)-h_plane(x)|
n_td proportional to [-h_x,-h_y,1]

若 slope、roughness、semantic boundary、unknown cell 或 rho_plane 超阈值，region 无效。Touchdown foot center 满足：

p_foot,z = h_plane(p_foot,x,p_foot,y) + foot_contact_offset
接口固定：selector -> p_td,target；region_builder(p_td,target,field) -> (A_td,b_td,n_td,plane)。中心是代价 reference，矩形和平面是 LQ 约束；二者不能混成一个 soft loss。

7. Warm nominal、事件 preview 与连续 swing

7.1 上一轮轨迹的关系

除 reset 后唯一一次 cold build 外，nominal 必须从上一轮最近一次有限选中轨迹 Z*_(t-1) 得到：

Z_shift[k] = Z*_(t-1)[k+1],  k=0,...,29
Z_shift[30] = terminal_fill(Z*_(t-1),command)

delta_p = p_measured-p_shift[0]
delta_yaw_phys = wrap(yaw_measured-yaw_shift[0])
delta_yaw_coord = yaw_measured-yaw_shift[0]

p_rebase[k] = p_measured + R_z(delta_yaw_phys)(p_shift[k]-p_shift[0])
yaw_rebase[k] = yaw_shift[k] + delta_yaw_coord
q_rebase[k] = q_shift[k] + beta_k(q_measured-q_shift[0])
beta_0=1, beta_k decreases to 0 within n_decay nodes
z_bar[0] = z_measured exactly

上一轮轨迹因此不会被丢弃：其 root、关节、速度趋势、swing 进度和末端事件都先被 shift/rebase；本轮地图只通过 large-only body corridor、重新选择的 touchdown、region、stance anchor 与 swing retarget 做结构化修正。small 场景不改写 root XY nominal；large corridor 激活时，root XY 使用同一 smooth window 从 rebase 轨迹连续混合到 p_B,corridor。

7.2 Stance 与 swing reference

continuing_i(k) = stance_i(k-1) AND stance_i(k)
onset_i(k)      = NOT stance_i(k-1) AND stance_i(k)

a_i(k) = persistent_anchor_i, current continuing stance
a_i(k) = selected touchdown on the local plane, future onset/stance

stance reference 整段保持 a_i。Swing reference 使用当前 measured foot position/velocity 或预测 lift state作为边界，并按本轮选中 touchdown 重新参数化。若 touchdown 在 H30 外，H30 内仍按绝对 gait phase 走向该目标，不能把 node 30 当作假 touchdown 或冻结脚；node 30 到真实 event 的 preview tail 同时保存并检查。

7.3 IK nominal 修正

给定 rebase root 与 foot reference，固定 branch 的 batched analytic IK 生成每腿关节 reference：

q_IK,i,k = IK_i(p_B,rebase,k,theta_B,rebase,k,p_foot,ref,i,k)
q_bar,i,k = q_rebase,i,k + gamma_i,k wrap(q_IK,i,k-q_rebase,i,k)

gamma_i,0 = 0
gamma_i,k = 1                         stance nodes
gamma_i,k = S(remaining_swing_phase)  affected swing nodes
z_bar[0] = z_measured                 final overwrite

gamma 只在与当前/下一 touchdown event 相关的腿段起作用。这样 nominal 既继承上一轮优化结果，又明确响应新地图和新命令。候选 reachability 已保证 IK 有限且在关节安全区；IK 不承担碰撞修补。

7.4 Nominal 自身安全

nominal 进入 LQ 前必须通过 touchdown region、stance anchor、joint bounds 和完整 swept safety。它不通过时不得寄希望于一次局部 LQ 从碰撞深处拉出；应尝试 selector 排名中的下一个安全 touchdown。全部候选均失败则本环境本周期 stop。

8. 一次 SQP/RTI 的 LQ 代价

在 nominal Z_bar 处令 Z=Z_bar+Delta Z，所有非线性 residual 只线性化一次：

r_j(Z_bar+Delta Z) ~= r_j(Z_bar) + J_j Delta Z

min_(Delta Z,s) 1/2 sum_j ||r_j+J_j Delta Z||_(W_j)^2 + J_slack(s)

固定行为代价为：

J = J_velocity + J_posture + J_root + J_swing
  + J_touchdown + J_smooth + J_warm + J_slack

8.1 Velocity tracking

v_B,k^body = R_z(yaw_k)^T(p_B,k+1,xy-p_B,k,xy)/dt
omega_k   = wrap(yaw_k+1-yaw_k)/dt

J_velocity = sum_k ||v_B,k^body-v_cmd,xy||_(W_v)^2
           + sum_k w_omega(omega_k-omega_cmd)^2

8.2 Posture hold 与 root 小幅适应

g_hold = exp(-||v_cmd,xy||^2/s_v^2) exp(-rho_terrain^2/s_rho^2)
J_posture = sum_k g_hold ||q_k-q_reset||_(W_q)^2

J_root = sum_k [w_z(z_B,k-z_support-ref,k)^2
              + w_rp||(roll_k,pitch_k)-(roll_0,pitch_0)||^2]
       + sum_k w_corridor(k)||p_B,k,xy-p_B,corridor,k,xy||^2
       + sum_k ||(Delta z_B,Delta roll,Delta pitch)/dt||_(W_root-rate)^2

rho_terrain 是当前 support/swing corridor 的固定 roughness 汇总。低速平地 g_hold 接近 1；速度或地形需要变姿态时平滑减弱，但 hard bounds 仍限制幅度。w_corridor=0 用于 flat/small，仅在 large encounter 激活。

8.3 Swing 与 touchdown

J_swing = sum_(i,k in swing) ||FK_foot,i(z_k)-p_swing,ref,i,k||_(W_swing)^2
        + sum_(i,k in swing edges) ||v_foot,i,k-v_swing,ref,i,k||_(W_swing-v)^2

J_touchdown = sum_(i,e) ||p_foot,i(k_td)-p_td,target,i||_(W_td)^2

J_touchdown 把解拉向安全矩形中心；硬 region 允许 LQ 在矩形内为关节连续性和 root 配合做小幅调整。若事件在 H30 外，当前 LQ 不虚构 endpoint residual，只由 H30 内 swing tracking 和 terminal preview residual 保持朝向该事件。

8.4 Smooth 与 warm consistency

J_smooth = sum_k ||z_k-z_k-1||_(W_1)^2
         + sum_k ||z_k-2z_k-1+z_k-2||_(W_2)^2

J_warm = sum_k ||z_k-z_bar,k||_(W_warm,k)^2

J_slack = sum_c [w_s,c ||s_c||_2^2 + w_s1,c ||s_c||_1]

J_warm 是 RTI trust/regularization 的可见表达，不允许掩盖新的 touchdown target。J_slack 只用于让线性 QP 有数值方向；任何使用 slack 后仍违反真实约束的候选会被 line search 拒绝。

删除旧做法：不再保留“41 个稀疏 body 点、约 1395 行统一归一化”的 ordinary full-body terrain soft loss。单次局部线性化、已碰撞 nominal、无 swept 检查和行数归一化会让梯度太弱；碰撞安全改由 nominal 预检、LQ 局部硬约束和 line-search 精确拒绝三层共同承担。

9. LQ/QP 硬约束

9.1 Measured、joint、trust 与 root

Delta z_0 = z_measured-z_bar,0 = 0

q_min+m_q <= q_bar,k+Delta q_k <= q_max-m_q
|q_k-q_k-1| <= qdot_max dt
|Delta p_B,k| <= trust_p
|Delta theta_B,k| <= trust_theta
|Delta q_k| <= trust_q

z_B,min(k) <= z_B,k <= z_B,max(k)
|roll_k-roll_ref| <= roll_max
|pitch_k-pitch_ref| <= pitch_max
|z_B,k-z_B,k-1|/dt <= zdot_max
|roll_k-roll_k-1|/dt <= rp_rate_max
|pitch_k-pitch_k-1|/dt <= rp_rate_max

9.2 全 horizon stance support

对每个 stance 节点，完整足端 XYZ 等于当前 persistent anchor 或该段 selected touchdown：

p_foot,i(z_bar,k) + J_foot,i,k Delta z_k = a_i,k

continuing current segment: a_i,k = persistent_anchor_i
future stance segment:      a_i,k = selected touchdown on local plane

这不是只约束 foot z，也不是只约束 x1。foot XYZ 被约束，root XY/姿态仍可改变；完整 Jacobian 中的 root 与 joint 列要求支撑腿关节同步补偿。线性化 equality 在 line search 中由真实 FK 再检查。

9.3 Touchdown region 与平面

A_td[p_bar,foot,xy+J_foot,xy Delta z_k] + b_td >= -s_td

p_bar,foot,z + J_foot,z Delta z_k
  = h_plane(p_bar,foot,xy)
  + grad(h_plane)^T J_foot,xy Delta z_k
  + foot_contact_offset

region 约束只施加在相应 touchdown onset 及其 stance segment；swing 节点不被矩形锁住，而是由 swing reference 和碰撞约束连续引导。

9.4 Foot、leg 与 base clearance

LQ 默认梯度布局使用固定 53 点/节点：

4 feet x 1 sphere       = 4
4 calves x 5 samples   = 20
4 thighs x 5 samples   = 20
base bottom 3 x 3      = 9
total                  = 53 points/node

knee 是 thigh/calf capsule 的共享端点，因此在 53 点表示中已覆盖；最终 detector 仍单独报告 knee。对点/部位 c：

d_c^nom = p_c,z^nom-H_(r_c)(p_c,xy^nom)
g_c = partial d_c / partial p_c

d_c^nom + g_c^T J_c Delta z_k >= r_c+m_c-s_c
s_c >= 0

large/unknown 的 H_(r_c) 是虚拟墙。base 约束同时检查底部 3x3 点，最终 safety 使用真实 oriented box；LQ 采样只负责提供局部方向，不构成安全证明。53 点是默认性能布局；若 finite-difference 或 exact-detector parity 证明某处没有提供正确的脱离方向，可在保持 foot/capsule/OBB 几何职责下调整样本布局，而不能缩小真实碰撞几何。

9.5 Slack 边界

0 <= s_collision <= s_collision,max
0 <= s_region    <= s_region,max
s_stance = 0 in the physical publication test

QP 可以用小 slack 产生恢复方向，但 line search 不读取“slack 已付费”作为可行证据。实际候选必须满足原始无 slack 约束，否则即使 nonlinear cost 更低也不可选。

11. 五候选硬安全 line search

Z^(j) = Z_bar + alpha_j Delta Z
alpha = [1,0.5,0.25,0.125,0]

五个候选共享本轮选中的 touchdown target 与 region；line search 不重新做离散选点。对 [B,5,31,18] 并行计算真实非线性代价和下列无 slack filter：

  1. 全部状态、FK、地图查询和代价 finite，且所有地图查询 valid。
  2. joint position/velocity、root z/roll/pitch/rate 和 trust bounds 通过。
  3. 所有 stance 节点用真实 FK 满足 XYZ anchor/ground tolerance。
  4. touchdown sole 完整位于本轮 convex region、安全语义和局部平面。
  5. 每个 swing node 与 node-to-node interval 的 foot sphere、knee、calf/thigh capsule 无碰撞。
  6. 每个 interval 的 base oriented box 无碰撞。
  7. small crossing 事件满足越障后方条件；large 轨迹不进入膨胀 forbidden 区。
  8. 事件在 H30 外时，node 30 到 touchdown 的 preview tail 同样通过 sweep。

上述所有地图 filter 只能查询当前 refresh 的 F_t/T_GW,t。五个 alpha 共用同一份当前 snapshot；若 snapshot freshness 检查失败，五个候选全部 invalid，而不是读取上一轮 line search 的 field。

feasible_j = AND(all exact filters for candidate j)
j* = argmin_j J_nonlinear(Z^(j)) among feasible_j

tie within epsilon_line -> choose larger alpha
no feasible candidate -> stop=true, publish=false

alpha=0 不是自动安全兜底，它也必须通过完整 filter。最终 swept detector 使用 foot sphere、calf/thigh capsules、knee endpoint、完整 sole 和 base oriented box；53 个 LQ 点不能替代它。碰撞检查是发布门，不是调权重后的偏好。

12. Cold-once / warm-only 生命周期

UNINITIALIZED --first optimize after explicit reset--> WARM_ONLY
WARM_ONLY     --every later optimize--------------> WARM_ONLY
WARM_ONLY     --explicit environment reset--------> UNINITIALIZED
  • 每个环境每个 reset lifecycle 恰好一次 cold nominal；第一次调用结束即设为 WARM_ONLY，与 line search 是否改善无关。
  • 之后 command 改变、地图改变、alpha=0、无安全发布候选或 optimization invalid 都不得触发 cold。
  • 每轮只把 finite 且通过硬安全的完整选中轨迹写入 accepted warm cache。
  • 无安全候选时保留最近一次 finite cache 和 touchdown metadata，但本周期输出 stop；下一周期仍从该 cache warm shift/rebase。
  • 已经 initialized 后 cache 缺失、shape 错误或 nonfinite 是 warm_cache_invariant_fault：停止该环境，不退回 cold，直到显式 reset。
  • persistent stance anchor 只在安全发布的 swing -> stance onset 更新；continuing stance 原样保留。

Cold build 只从 measured state、reset posture、command、gait 和本轮安全 touchdown 构造首条有限轨迹；它不是运行期恢复策略。

15. 完整指标公式、证据来源与阈值

15.1 证据分层和禁止误报

每个行为指标同时标记数据来源：

P: planner selected trajectory, converted to world geometry by FK
A: actual root/joint articulation readback, converted to world geometry by FK
M: current-refresh semantic/elevation/valid map and T_WG transform
V: viewer overlay generated from the same P/A/M trace

formal_behavior_pass = pass(P queried on M) AND pass(A queried on M)
canonical_visual_pass = pass(V) for every required canonical trace
  • P 通过但 A 在同帧 M 上失败，整个 cell 失败；不能称为“规划通过、只是 viewer 不对”。
  • Isaac 只提供 root pose 和 joint position readback；不读取 contact report、contact force、impulse 或任何动力学量。
  • M 必须与对应的 P/A state 同 refresh；旧一帧地图即使内容 finite 也属于 invalid evidence。
  • fixture 必须与 terrain task 的 native sphere/cuboid/cylinder/capsule/cone 几何和高度一致，不能用平顶近似 sphere/capsule。
  • 地图随 measured root 更新，障碍保持固定 world pose；障碍不得跟随局部 field origin 移动。
  • 每条 formal trace 必须从事件前开始，经过完整 swing、touchdown，并在 touchdown 后继续至少一个完整 24-frame gait period。
  • 没有产生 crossing attempt、停在障碍前、从障碍旁绕过、越过后没有安全 touchdown，均记 strict-cross failure，不记 N/A 或 success。
  • canonical viewer 证据至少覆盖五类 small shape，各自低/中/高三个前向速度 0.2/0.6/1.0m/s；15 条实际 readback trace 必须逐条成功，不能用总体百分比隐藏肉眼失败。

15.2 通用记号与聚合

V_k       : valid trajectory/map frame mask
E_k       = V_k AND V_(k-1)
C_i,k     : leg i is stance
CC_i,k    = C_i,k AND C_i,k-1 AND E_k
SW_i,k    = NOT C_i,k AND V_k
N(A)      : valid elements in set A

15.7 碰撞指标：世界坐标 FK 几何与同帧地图

对 refresh t、部位 b 和 horizon node k，planned H30 与本 refresh 真正读回的 actual state 分别经过同一纯运动学 FK，得到世界坐标几何：

G_b,W^P(t,k) = FK_geometry_b(z_selected(t,k))
G_b,W^A(t)   = FK_geometry_b(z_measured,t)

Q_t(G_W) = query current F_t at project(T_GW,t G_W)
d_b^P(t,k) = signed_clearance(Q_t(G_b,W^P(t,k)))
d_b^A(t)   = signed_clearance(Q_t(G_b,W^A(t)))

semantic_hit_b^P(t,k) = 1[footprint(G_b,W^P(t,k)) intersects forbidden S_t]
semantic_hit_b^A(t)   = 1[footprint(G_b,W^A(t)) intersects forbidden S_t]

collision_b^P(t,k) = 1[d_b^P(t,k)<0] OR semantic_hit_b^P(t,k)
collision_b^A(t)   = 1[d_b^A(t)<0] OR semantic_hit_b^A(t)

所有 capsule、sphere、sole 和 OBB 都先保留世界坐标，再统一通过 T_GW,t 查询当前 H_t/S_t/V_t。stance foot sole 位于 normal ground 且满足 ground tolerance 是合法支撑；swing foot 低于当前有效高程、任意 foot 覆盖 small/large、knee/calf/thigh/base 低于当前有效高程或进入 forbidden semantic 均是碰撞。这里没有 contact、force、impulse 或动力学判据。

15.8 Strict small-cross 事件

对命令轴 e_cmd 和一次相关 swing event，每个 refresh 都从当前 semantic map 重建 small footprint 的世界坐标集合：

O_s,t^W = {project_xy(T_WG,t g) | g is a cell in current M_s,t}
s(x) = e_cmd^T(x-p_lift,xy)
s_in(t)  = min_(x in O_s,t^W) s(x)
s_out(t) = max_(x in O_s,t^W) s(x)

before = s(p_lift)<=s_in(t_lift)-d_pre
over_xy = exists t in swing: sole_xy^W(t) intersects O_s,t^W
over_z  = min_(t where over_xy)[sole_bottom_z^W(t)-H_small,t^W(sole_xy^W(t))]>=m_cross
after   = s(p_touchdown)>=s_out(t_touchdown)+d_landing
land_ok = complete sole on normal ground AND NOT on small/large/unknown
body_ok = all foot/knee/calf/thigh/base collision flags are false in full event window

strict_cross = opportunity AND before AND over_xy AND over_z AND after AND land_ok AND body_ok

opportunity 由当前帧地图映射到世界坐标的 obstacle、command corridor 和 gait event 共同定义，不能依赖 planner 是否选择跨越来消失。事件可以保存 world obstacle id/中心用于跨帧关联，但每一帧的 footprint、高程和碰撞都必须重新读取 M_t，不能缓存进入事件时的旧地图。over_xy 明确排除从侧面绕过，after 排除碰到后退回，完整 event window 排除 crossing 当帧截断后隐藏 touchdown 碰撞。

16. 1024 环境性能门

正式门的含义固定为：

B = 1024
H = 30
refresh_count = 1000 warm-only calls
T_total(W) = CUDA-event elapsed time for 1000 complete planner refreshes
W in {flat-only,small-only,realistic-mixed}

max_W T_total(W) < 5.0 s
T_refresh(W) = T_total(W)/1000 < 5.0 ms
throughput(W) = 1024*1000/T_total(W) > 204800 environment-refresh/s

计时包含：每 refresh 的当前语义/高程 field build、max-pool layers、touchdown event/candidates、convex region、nominal retarget/IK、一次 linearization、一次 scan LQ/QP、五 alpha 的 nonlinear cost和完整 swept filters、cache/diagnostics tensor 更新。计时不包含 scanner 上游仿真渲染、首次 import、kernel compilation 和 CUDA Graph capture；同帧地图输入已经位于 GPU，禁止在循环内 host-device copy，也禁止通过复用上一帧 field 降低耗时。

flat-only、small-only 和 realistic-mixed 三个 workload 各自先 warm up 100 次，再独立运行 5 组 1000 refresh；每个 workload 的五组均须 <5.0s，并分别报告 median、max、峰值显存和 graph replay 次数。small-only 必须包含五种真实 shape、不同 gait phase/offset 和全部安全检查；realistic-mixed 同时含 flat、small、large，不允许用全零地图或 flat 平均耗时掩盖 small 变慢。性能优化不得减少 25 候选、完整 line-search swept filter 或安全 margin；LQ 采样布局的修改必须保持 exact-detector 方向覆盖和 scan parity。

19. 最终完成定义

  1. 生产代码的数据流逐项对应第 3 节，且一次 refresh 只有一次 SQP linearization、一个 LQ/QP 和五个固定 alpha。
  2. 优化和 detector 均保持纯运动学：只有 root pose、joint position、FK 几何和有限差分，不存在动力学状态、接触力、冲量、力矩或 Isaac contact sensor 输入。
  3. Touchdown 每轮选择、H30 外 event preview、convex region、continuous swing、full-horizon stance 和 warm-only lifecycle 均有公式级单元测试。
  4. max-pool field 与真实 scanner 在 world/grid、语义、native shape 高程、unknown/map boundary 上 parity；每轮 map_age_frames=0，frame mismatch 为 0。
  5. FK/IK/Jacobian、collision gradient、region plane、LQ residual 用 finite difference 验证；scan/dense 误差小于 2e-5。
  6. 五 alpha 的每个 hard filter 有 RED/GREEN 测试；任何 foot、knee、calf、thigh、base 或 swept interval 碰撞都不可发布。
  7. 严格按 Gate 0 到 Gate 4 推进：先让 flat 的 M_common 全绿，再让 small 的全部 M_common union M_small 全绿；不得用 crossing 成功率或总体均值掩盖 small 中的 common 回归。
  8. 第 15 节所有适用指标按同一 trace schema 计算，flat 与 small 各自形成完整 report，P/A/M source 同时通过；15 条 canonical small viewer trace 逐条 strict-cross 且零碰撞。
  9. Viewer 使用生产 backend，一次 SQP，所有调参都可从画面和同次 diagnostics 看出实际变化。
  10. 1024 x 1000 的 flat-only、small-only、realistic-mixed warm refresh 各五组均小于 5.0s，无 host sync、per-env Python loop 或动态分配回归。
  11. 每个无 reset rollout 只有一次 cold；随后 cache/line-search 失败也只走 warm 或 stop，绝不隐式 cold restart。
  12. 旧 repair、soft collision 和重复 solver 不在生产调用图中，已按第 18 节删除；文档、配置、测试和 viewer 不暴露失效参数。
