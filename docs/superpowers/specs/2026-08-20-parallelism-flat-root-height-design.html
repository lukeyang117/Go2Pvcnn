Parallelism Mixed Terrain Root 高度与障碍物设计

日期：2026-08-20　状态：待实现设计　范围：large train / play / distillation / viewer
核心结论：统一 mixed terrain 配置；flat 和 flat_dense_small_obstacles 使用平地基准面加 0.30m 的固定 root target， 小障碍物只参与足端规划，不参与平地 root 高度生成。

一、问题与根因

当前 planner 的平地 root 高度不是固定值，而是读取当前 stance 足端下方的高程，再加上 root_clearance_m：

stance_height = query_height(stance_foot_xy)
root_z = stance_height + root_clearance_m

当某条腿踩在小障碍物上时，查询到的 stance_height 包含小障碍物高度，root 参考轨迹就会被整体抬高。

同时，flat_dense_small_obstacles 当前没有被识别为平地。reference manager 只把名称严格等于 flat 的 terrain 视为平地，因此 dense flat 可能进入 terrain-following 分支，读取 root XY 下方的高程，同样会受到小障碍物影响。

需要避免的错误：不能通过删除语义高程图、删除 touchdown 高度或关闭碰撞检测来解决。问题只在 root 高度来源，不在足端规划本身。

三、Terrain 课程与环境分配

当前 terrain curriculum 继续保留，但只排除 flat_dense_small_obstacles。dense flat 用于固定密集小障碍物训练， 不参与 terrain level 提升，避免把障碍物数量与地形课程混在一起。 

excluded_terrain_names = (
    "flat_dense_small_obstacles",
)
  • flat 保留在 terrain curriculum 中，只有 large obstacle。
  • flat_dense_small_obstacles 固定为 40 个 small obstacle，不随 terrain level 增加。
  • rough、slope、boxes、stairs 继续按原 terrain level 逻辑运行。
  • 环境数量按 terrain generator 比例分布；dense flat 的目标比例为 0.1。

四、Flat Root Target 的确定

flat 和 dense flat 使用相同的基础平面，因此 root target 采用：

target_root_z_flat
    = flat_base_z + flat_root_clearance
    = 0.00m + 0.30m
    = 0.30m

配置语义为：

flat_base_z_m: float = 0.0
flat_root_clearance_m: float = 0.30

flat_base_z_m 指 MeshPlane 的基础地面高度，不是高程图中某个局部采样点。 dense flat 的 40 个小障碍物是后续语义物体，不能改变 flat_base_z_m，因此两类 flat 使用同一个 0.30m target。

不使用 stance 足端高度、root XY 下方局部最高点或小障碍物顶部高度来确定 flat root target。

flat target

每次 reset 或重规划时：

root_z_ref[0] = root_z_actual
root_z_ref[t] = smooth(root_z_actual, 0.30, t), 1 <= t < 24

第 0 帧继续用于保证 reference 与真实机器人对齐。第 1～23 帧回到 target_root_z_flat，避免当前 root 因站在小障碍物上而把整个 reference 抬高。

root 的 XY 轨迹、yaw 轨迹、平地 roll/pitch 回正逻辑不变；复杂地形不走这条固定高度路径。

六、规划数据流与影响边界

6.1 平地类地形

command
  ↓
root XY / yaw rollout
  ↓
flat_base_z_m + flat_root_clearance_m = 0.30
  ↓
root reference
  ↓
foot touchdown / swing 高程查询
  ↓
IK 与几何碰撞检测

高程图仍然会进入足端规划，但不会进入平地 root 高度计算。

6.2 复杂地形

command
  ↓
root XY / yaw rollout
  ↓
root XY 下方高程查询
  ↓
terrain-following root Z 与 roll/pitch
  ↓
foot touchdown / swing / IK / collision

这条路径保持现有实现，不使用固定的 0.30m。

6.3 足端规划不变

高程图仍然用于 touchdown 高度、swing clearance、IK 和 geometry collision。 本设计只切断“小障碍物高程 → flat root 高度”的路径，不删除障碍物对足端规划的作用。

八、验证标准

  1. terrain generator 的八类 terrain 比例总和为 1.0，比例与本设计表一致。
  2. flat obstacle 数量为 small=0、large=2；dense flat 为 small=40、large=0；其他 terrain 为 small=5、large=2。
  3. 在 flat terrain 中，把局部高程从 0.00m 改为 0.10m，root reference 的第 1～23 帧目标高度仍为 0.30m。
  4. 在 flat dense terrain 中，即使 root XY 正好位于小障碍物上方，也不能进入 terrain-following root 分支。
  5. reference 第 0 帧仍等于当前 IsaacLab 真实 root 状态。
  6. rough、slope、boxes、stairs 的 root Z 仍随高程图变化。
  7. standstill fallback 不再通过小障碍物高度抬高 flat 类 terrain 的 root。
  8. 现有足端 touchdown、swing clearance、IK 和 geometry collision 测试继续通过。
验收结果：平地上的小障碍物只改变腿和足端的规划约束，不改变 root 的默认参考高度。

九、范围边界

  • 本设计只解决 root 高度被 flat 类小障碍物抬高的问题。
  • 不改变 Parallelism 的 touchdown 候选采样半径。
  • 不改变 swing clearance 的配置。
  • semantic obstacle 数量和 terrain 比例按本设计统一修改。
  • 不改变 RL 的 observation、reward、termination 或 curriculum 定义。
  • 不把复杂地形错误地当成固定高度平地。
