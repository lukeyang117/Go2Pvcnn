1. 目标、范围与完成顺序

本阶段目标

  • 使用纯运动学状态和一次 SQP/RTI，生成可发布的 H30 root-joint 轨迹。
  • 先通过全部平地指标，再通过全部小障碍跨越指标。
  • 平地和小障碍共享同一套 trace、指标公式、阈值系统与真实状态来源。
  • 固定形状 GPU 并行，可扩展到 1024 个训练环境。
  • 保留未来接入强化学习 reference 的清晰输出接口。

本阶段非目标

  • 不引入动力学、接触力、力矩或独立速度优化变量。
  • 暂不验收上楼梯、下楼梯、坡地和大障碍绕行行为。
  • 不在线优化 gait topology、摆动顺序或接触时刻。
  • 不增加第八类 loss，不使用输出后的 IK 或碰撞修补。
  • 不在 nominal 阶段通过语义搜索候选落脚轨迹。

3. 感知场合同

感知仍是二维高程图和二维语义图，不构造三维体素：

H[x,y] : elevation
S[x,y] : semantic label
A_s[x,y], A_l[x,y] : small/large 卷积软占用层
H_s[x,y], H_l[x,y] : 卷积传播后的分类障碍高度
G_s[x,y], G_l[x,y] : 卷积软占用层的显式 XY 梯度
可导对象：语义标签本身仍是离散观测；MPC 需要的是 terrain loss 对轨迹查询坐标 p=(x,y) 可导。禁止直接把 semantic_id == class 的硬跳变送入 LQ/GGN。

3.1 固定卷积软语义场

先从离散语义图生成 small/large 二值 mask：

M_s(x,y) = 1[S(x,y) == small]
M_l(x,y) = 1[S(x,y) == large]

每类使用固定的世界尺度高斯核：

K_c(dx,dy) = exp(-(dx^2 + dy^2) / (2 sigma_c^2))
C_c = K_c * M_c
A_c = 1 - exp(-lambda_c C_c)

sigma_c 控制连续影响范围，lambda_c 控制占用饱和速度。核大小、padding 和 sigma 在图捕获前固定；small/large mask 使用固定通道 grouped conv2d 一次处理整个 batch，不按环境、像素或类别使用 Python 循环。

3.2 卷积传播分类障碍高度

语义范围扩展到物体外侧时，必须同时传播该类物体高度，不能重新读到外侧地面高度：

N_c = K_c * (M_c H)
H_c = N_c / (C_c + epsilon)

H_c 只作为该类障碍的连续局部高度；原始 elevation H 仍是普通地面和接触面的依据。

3.3 显式梯度与双线性查询

使用固定 Scharr 卷积核生成空间梯度：

G_c,x = K_x * A_c
G_c,y = K_y * A_c

轨迹节点使用双线性采样：

a_c(p_k) = bilinear(A_c, p_k)
grad_p a_c(p_k) = bilinear([G_c,x, G_c,y], p_k)

LQ/GGN 通过链式法则得到对 18 维状态的方向：

dJ/dz_k = (dJ/da_c) (da_c/dp_k) (dp_k/dz_k)

最后一项由 foot/knee/calf/thigh/base 的完整 FK Jacobian 给出。卷积、Scharr 和 packed bilinear query 必须保持固定形状并可进入 torch.compile 与 CUDA Graph。

4.2 Cold start

触发条件：每个环境生命周期只允许一次。仅当该环境从未初始化，或该环境收到显式 reset 后，执行一次 cold start；完成该次调用后立即进入 WARM_ONLY，直到下一次显式 reset。上一轮候选不改善、line search 选择 alpha=0、新解无效、command/地图变化、shape 检查失败或 NaN/Inf 均不得触发 cold start。

  1. 固定 z_bar[:,0] = z_measured。
  2. 由 command 一次产生全部 yaw，并用世界系位移的 cumsum 产生 31 个 root XY 节点。
  3. root z、roll、pitch 从 measured/support nominal 初始化。
  4. touchdown XY 只由 command、gait phase 和 nominal footprint 产生，不根据语义地图搜索或改写。
  5. 所有 touchdown XY 打包查询真实高程，得到 touchdown z。
  6. 所有 swing 足使用解析插值和同一个基础摆高参数：
p_foot_xy(tau) = (1-tau) p_lift_xy + tau p_td_xy
z_foot(tau) = (1-tau) z_lift + tau z_td + h_swing 4 tau (1-tau)

h_swing 是可调参数，建议初值 0.08 m；它不等于每个查询点的 terrain clearance，后者仍由地形高度和部位安全余量决定。最后用 batched analytic IK 一次得到 [B,31,4,3] 关节角。

4.3 Rolling warm start

触发条件：该环境已经完成本生命周期唯一一次 cold start 后，每个 RTI 周期无条件进入 warm start。它只负责继承最近一次有限的已选择轨迹并与当前测量连续连接，不负责根据地形或语义重新规划动作。

UNINITIALIZED --cold once--> WARM_ONLY --explicit env reset--> UNINITIALIZED

Runtime 必须保存每个环境的 last_finite_selected_trajectory。五个 line-search candidate 包含 alpha=0 的 shifted warm nominal，因此一次 LQ/line-search 没有改善时仍有有限的下一轮轨迹，不能把“没有新优化步”解释成“没有上一轮解”。无效或 nonfinite candidate 禁止写入 warm cache；继续保留本轮 alpha=0 或最近一次有限轨迹，并通过 loss、尺度、regularization、trust region 和 Jacobian 一致性修正后续优化。

Warm state 还保存 stance_anchor_w[B,4,3]。它不是优化变量，也不增加 loss、KKT 约束、line-search filter 或 recovery 分支；它只记录每条腿最近一次有效 touchdown 的世界坐标。cold row 从当前 measured FK foot 初始化，连续 stance 跨 RTI 原样保留，只有有限且将要发布的 x1 出现 swing -> stance 时才更新对应腿。显式 reset 只清除 initialized，下一次唯一 cold build 会用测量足端覆盖该 row 的旧 anchor。

Z_shift[:,0:30] = Z_prev_star[:,1:31]
q_shift[:,30] = q_prev_star[:,30]  # hold the last accepted terminal joint state

用 measured state 与上一轮预测 x1 的误差一次性重定位全部 root 节点：

delta_p = p_measured - p_prev_star[1]
delta_yaw_physical = wrap(yaw_measured - yaw_shift_0)
delta_yaw_coordinate = yaw_measured - yaw_shift_0
p_bar_B,k = p_measured + Rz(delta_yaw_physical) (p_shift_B,k - p_shift_B,0)

2026-07-21 yaw 连续性 amendment：wrap 只用于 SE(2) 位置旋转所需的最短物理角差，禁止对 31 个 yaw_bar_k 节点逐点 wrap。yaw 坐标差把整条 shifted horizon 一次性搬到 measured yaw 所在的 2*pi 分支，因此 x0 仍与 measured 数值相等，horizon 内相邻 yaw 连续。逐节点 wrap 会在预测尾部先越过 +/-pi 时制造约 2*pi 的假跳变，使 Command 和 Smooth 反向拉回 yaw，并经 FK/Contact 耦合产生虚假的 root RPY 与 stance slip。

关节 measurement mismatch 使用固定衰减向量修正前几帧：

q_bar_k = q_shift_k + beta_k (q_measured - q_shift_0)
beta_0 = 1, beta_k -> 0 in the first configured nodes

最后严格覆盖 z_bar[:,0]=z_measured，重新生成 gait/reference 和 packed map query。新地图进入后续 loss/Jacobian，不通过 hidden repair 改写 nominal XY。

2026-07-21 stance-anchor 一致性 amendment：当前 horizon 起点已经处于 stance 的足，anchor 取 persistent measured/warm anchor。不得把 shifted warm FK 当作新的 persistent anchor。

2026-07-21 future-contact amendment：当前已激活 stance 强绝对锁 persistent world anchor。future onset 只用弱 touchdown reference 引导第一帧落脚，future continuing stance 再使用强相邻足端差分抑制滑动。把 onset 也改成强相邻锁定的实验会继承错误的高位 swing endpoint，产生 87mm stance gap、3.57mm slip 和 0.4605rad joint step，已拒绝。该修正仍属于同一个 Contact loss，不增加优化变量、候选点、地图搜索、硬约束或第八类 loss。

e_current_i(k) = p_i(z_k) - a_i_persistent,  stance active at k=0
e_onset_i(k)   = p_i(z_k) - p_i,target(k),   future onset, weak
e_future_i(k)  = p_i(z_k) - p_i(z_(k-1)),   future continuing stance
weight(e_onset) << weight(e_future)
Warm-start 白名单（Task 14E 修订）：生产路径只允许 shift、root rebase、joint mismatch decay、tail fill、x0 overwrite，以及下面显式定义的 published-x1 continuing-stance manifold initialization。除这六步外的 terrain projection、semantic search、全 horizon IK、swing/onset IK、startup/recovery shaping 或其他 contact-dependent trajectory rewrite 均不属于 warm start。WARM_ONLY 中若缓存缺失、shape 错误或 nonfinite，视为 solver invariant fault：禁止退回 cold；runtime 必须显式报告并停止该环境发布，直到环境 reset。

5.1 Early command 的滚动一致性 amendment

早期摆动 command 子权重只用于当前待发布的第一条 edge，不用于 horizon 内未来的每个 swing 边界：

c = 1 - exp(-||v_xy||^2 / s_cmd^2)
e_0 = max_i [ (1-tau_{0,i}) 1[swing_{0,i} and swing_{1,i}] ]
w_cmd,0 = 1 - (1-w_early) c e_0
w_cmd,k = 1, k=1,...,29

其中 s_cmd 是固定的小 activity scale。该 early 权重只乘 linear command residual：零平移或纯 yaw 时 c=0，因此 XY hold 与 yaw residual 都不会被放松；非零平移命令的当前第一条 swing edge 才允许让 foot 先启动。未来 edge 保持完整 command 压力，避免一个尚未发布的 gait 边界被优化成 kink，再由 rolling warm shift 推入 x1。这仍属于 command loss 的已批准 subweight，不增加 loss、状态变量、KKT 行、candidate 或 filter，也不增加跨时间 Jacobian 带宽。

Cold nominal 必须与该首边目标一致：启动时 root_nom,1=root_measured，从 edge 1->2 起才按 command_scale 积分 root pose。否则 LM regularization 会把一次 RTI 方向拉回一个首边已前进的 nominal，即使 w_cmd,0=0 也无法形成规定的 foot-before-root 启动顺序。该规则只修正已有 cold nominal 的第一条 increment；warm shift、七项 loss、KKT 和 line search 结构不变。

5.2 Zero-command hold 的连续权重 amendment

纯软目标下，零值 Command residual 分量虽以零速度为目标，但 Contact、Posture、Terrain 和 Smooth 仍可通过微小 root 位移降低总损失。为在不增加 hard branch 或 projection 的前提下满足静止合同，linear 与 yaw 分量使用独立、连续的 hold multiplier：

m_xy(v_xy) = 1 + (m_0 - 1) exp(-||v_xy||^2 / s_cmd^2)
m_yaw(w)   = 1 + (m_0 - 1) exp(-w^2 / s_cmd^2)
J_command  = m_xy J_command,xy + m_yaw J_command,yaw

m_0 >= 1 是允许调节的 Command 子权重，s_cmd 与 5.1 使用同一 activity scale。纯 yaw 时仍压住 XY drift，纯平移时仍压住 yaw drift；对应正式非零分量远大于 s_cmd 时各自趋近 1。实现必须通过各 residual 分量的平方根缩放进入 nonlinear loss 与同一 GGN Jacobian，禁止只改 line-search score。

6. 一次 SQP/RTI、LQ 与 KKT

每个控制周期只执行一次 SQP iteration：

measured/map/command
  -> vectorized nominal/warm start
  -> 七项 nonlinear loss 在 nominal 处线性化/GGN 二次化
  -> constrained LQ/QP
  -> associative scan 求方向 delta_Z
  -> parallel line search
  -> 接受 Z_star 并只发布 x1

KKT 只承载已批准的硬约束：

  • z_0=z_measured：固定或从变量中消元。
  • joint position bounds。
  • -qdot_max dt <= q_(k+1)-q_k <= qdot_max dt。
  • SQP trust region。

Root position trust 按预测节点累计：对 k=0..30，|delta p_(B,k)| <= k Delta_p。因此 delta p_(B,0)=0，每跨过一条预测 edge 最多新增一份位置修正预算，而持续的速度修正可以在 horizon 内累计。Root orientation 与 joint trust 仍是逐节点常数 box。该定义只改变现有 merged trust box 的数值，不增加 KKT 行、约束类别、loss、candidate 或 filter。

terrain、collision、small touchdown 不进入新的 general KKT 行，由固定七项 loss 统一处理。旧设计的 32 行是资源上限而不是新设计目标，禁止重新用 startup/recovery/collision 分支填满。唯一例外是 2026-07-22 批准的 published-x1 当前 stance 保持约束；它使用固定 6 行低秩 Schur KKT 修正，不占用每 interval 的 30 行 box/velocity active-set 预算。

7. Associative Scan

二阶 smooth 使原始 QP 呈 block-pentadiagonal。求解器内部使用 separator：

y_k = [delta_z_(k-1), delta_z_k] in R^36

它只是 Gaussian/KKT factor composition 的内部表示，不是新增优化变量。30 个 interval pad 到 32，使用 5 层固定 H30/32 combine tree。不得依赖当前 PyTorch 2.7 已知会在 symbolic-vmap matmul 失败的通用 associative_scan 路径。

生产接入前必须满足：

||delta_Z_scan - delta_Z_dense||_inf < 2e-5

并分别验证 combine 结合律、active bound 固定形状、梯度/解有限性和 H30 padding 不改变原问题。

8. Parallel Line Search

alpha = [1.0, 0.5, 0.25, 0.125, 0.0]
Z_alpha = Z_bar + alpha * delta_Z

五个候选在固定 [B,5,31,18] 张量中并行生成。只允许依次过滤：

  1. NaN/Inf；
  2. joint position violation；
  3. joint velocity violation。

剩余候选只按同一套七项 nonlinear total loss 选择：

alpha_star = argmin_(alpha in feasible) J_seven_losses(Z_alpha)

近似同分选择更大的 alpha；alpha=0 是 nominal fallback。禁止 nominal safe/unsafe 分支、collision hard gate、foot-on-small hard gate、额外 merit/violation 排序、recovery candidate 和输出后 projection。
