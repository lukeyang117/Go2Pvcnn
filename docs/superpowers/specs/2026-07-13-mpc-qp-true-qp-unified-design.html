MPC-QP 真正 QP 联合优化设计

日期：2026-07-13。目标是在不新建 solver 文件、不改老 mpc 的前提下，把 mpc_qp 从“联合 loss + autograd 梯度步”改成真正的 batched dense QP / least-squares 联合求解；同时冻结指标定义、冻结 loss key，只允许后续调整 loss 权重与 QP 求解超参。

绝对边界：不允许任何梯度下降方法，不允许 torch.autograd.grad() 作为主路径，不允许候选搜索、repair、snapping、decode projection，不允许新增或删除 loss key。本设计写定后，不允许再新增、删除或重定义验收指标。若结果不理想，只能调 loss 权重、damping、step clamp、采样密度，并且 QP iteration 只允许维持或低于默认上限 3。
本设计的核心约束：所有 loss 在每次 QP iteration 中必须同时进入同一个 QP/LS 系统联合求解；运行时禁止 lossA -> lossB 的顺序修变量；规划 horizon 保持 25 帧，验收统计采用多个 25 帧片段拼接成 500 帧 rollout。

1. 目标

轨迹质量

root z 不乱抬、不瞬移，foot / FK 贴合到 0.005m 级，小障碍可跨越，semantic / ground / body / knee / shank 碰撞为 0。

求解方式

真正的 QP / least-squares 联合求解，不使用梯度下降，不使用 autograd 反传做主更新。

长期验收

Row8/Col12 使用 25 帧 receding horizon，但将 25 帧片段拼接到 500 帧长 rollout 上做统计，检查长期稳定性。

2. 设计边界

  • 只修改 Go2Pvcnn/extension/batch_mpc_qp_planner/ 里现有代码文件，不新建 solver 模块文件。
  • 不改老 mpc 的实现、loss、指标或测试逻辑。
  • mpc_qp 主路径必须是联合 QP / LS solve，不能退回 autograd 梯度步。
  • loss key 冻结，不新增、不删除、不重命名。
  • 本设计列出的指标定义冻结，不改公式、不改语义，只能按本设计给出的阈值做验收。
  • 后续仅允许调整 loss 权重、damping、步长、变量缩放、采样密度；QP iteration 默认上限为 3，只能维持或减少，不能为了过指标继续加次数。

3. 决策变量

本设计不把 joint_angles 作为优化变量。joint 由 IK/FK 派生，但 joint 相关 loss 会通过解析或近似 Jacobian 进入同一个 QP。

变量 形式 说明
root 单段 cubic Bezier 仅优化 xyz + yaw。不优化 roll/pitch。P0 固定为当前 root，P1/P2/P3 为控制点。
foot 每条腿单段 cubic Bezier P0 固定为当前足端；优化 P1/P2 xyz + P3 xy；P3 z 绑定地形高度图，不作为自由变量。
joint_angles 派生变量 由 root 曲线采样与 foot 曲线采样经 IK/FK 派生，不直接优化，但 joint limit / joint smooth / joint jump residual 会进入 QP。

推荐的总变量仍为固定形状 batched dense 向量，单环境约 44 维左右；具体 pack/unpack 可在现有 coupled_solver.py 内部完成，不新建文件。

4. 真正 QP/LS 形式

每次 QP iteration 必须把所有已定义 residual 一次性装配进同一个线性化系统：

min_dx  ||J_1 dx + r_1||^2 + ||J_2 dx + r_2||^2 + ... + damping ||dx||^2

然后解出同一个 dx，统一更新 root / foot 控制点。禁止先优化 semantic 再优化 clearance，再优化 FK 的顺序修变量模式。

5. Loss 设计

下面这些 loss key 维持现有名字，不增不减。当前实现可以仍然记录到 loss_breakdown / cost_breakdown，但求解主路径必须改成 residual block + Jacobian + QP/LS solve。

Loss key 是什么 主要作用变量
qp_coupled_touchdown_semantic_loss落脚点不能踩语义物体。foot P3 xy
qp_coupled_touchdown_quality_loss落脚点附近地形质量要好，偏向平整/可落脚区域。foot P3 xy
qp_coupled_swing_loss摆腿阶段要有 clearance，不能刮地。foot P1/P2 z 与部分 xy
qp_coupled_terrain_clearance_loss足端不能穿地，净空要足够。foot 曲线
qp_coupled_crossing_loss小障碍跨越的整体形态约束。foot P1/P2/P3 + root
qp_coupled_low_small_arc_height_loss跨小障碍时弧线高度不够的惩罚。foot P1/P2 z
qp_coupled_low_small_arc_lane_loss跨越 lane 横向不对。foot P1/P2 xy
qp_coupled_low_small_arc_along_loss跨越 along 方向位置不对。foot P1/P2/P3 xy
qp_coupled_low_small_progress_lossroot 需要真正前进，不允许原地抖。root 曲线前进方向
qp_coupled_low_small_root_lift_loss跨小障碍时 root 不能被小物体抬高。root z 曲线
qp_coupled_low_small_endpoint_progress_loss终点需要越过障碍，不要停在障碍前。foot P3 xy
qp_coupled_low_small_sample_crossing_loss整条 foot 曲线采样点都要跨越安全。foot 曲线整体
qp_coupled_readback_loss规划足端与 FK 回读足端一致。root + foot + IK/FK 耦合
qp_coupled_body_loss膝、胫、身体底部采样点不能碰地形或语义物体。root + foot 联动
qp_coupled_root_lossroot 高度范围要合理，不能过低或过高。root z 曲线
qp_coupled_root_z_jump_lossroot z 相邻帧跳变不能过大。root z 曲线
qp_coupled_continuity_lossfoot 和 joint 的时间连续性，抑制抖动。root / foot 连续曲线
qp_coupled_loss_total以上所有 loss 的总和，只用于记录。汇总项

Joint 相关的要求：joint 不作为变量，但 joint limit、joint smooth、joint jump 必须通过解析/近似 IK Jacobian 一起进入 QP。禁止把 joint loss 退化成 autograd 梯度下降。

7. Row8/Col12 长轨迹协议

Row8/Col12 的评测不是短程起步验证，而是长轨迹稳定性验证：

  • 规划 horizon 保持 25。
  • 验收窗口固定为 500 帧。
  • 500 帧由 20 个 25 帧 receding horizon 片段拼接得到。
  • 每个片段的第 0 帧状态来自上一片段实际播放后的末帧，而不是重新从初始状态启动。
  • 每个片段仍调用同一个 mpc_qp 真 QP 求解器，不能为长轨迹测试引入额外 repair、候选或后处理投影。
  • 重点看长期累计误差，而不是前几帧“看起来过了”。

拼接后的 500 帧轨迹需要保留每帧的 root、planned foot、FK foot、joint、contact、touchdown、terrain/semantic collision 诊断。单段 25 帧指标继续保留，用于定位是哪一个片段出问题；最终验收以 500 帧聚合指标为准。

Row8/Col12 的长期验收关注：

  • root z 是否始终稳定。
  • FK / planned 是否长期贴合。
  • 地面穿透、semantic 碰撞是否始终为 0。
  • 跨越后是否还能继续稳步前进，不在中途退化。

8. 实现边界

  • 不新增 solver 文件；若需要辅助函数，只能放在现有 coupled_solver.py / planner.py 的内部 helper 中。
  • 不新增 loss key；不删除 loss key；不重命名 loss key。
  • 本设计确定后不再新增 metric 定义；不修改 metric 公式；只允许调权重和阈值解释。
  • 不允许任何梯度下降路径成为主求解方式。
  • 所有已实现 loss 必须在同一 QP iteration 中联合 solve。
  • 只保留 25 帧 planning horizon；500 帧仅用于评测拼接。

9. 验收标准

场景 通过标准
平地 / 无 semantic root z 平稳，footprint 规整，FK / planned foot 贴合，旧硬指标不退化。
dense small obstacle 必须出现 swing-over opportunity 且 success；small 语义碰撞为 0；root z 不乱抬；true overpass acceptance = 1。
Row8/Col12 500 帧 stitched rollout 中，ground/semantic/body/fk 指标持续为 0 或不退化；long-horizon stability 通过。

10. 非目标

  • 不做候选落脚点搜索。
  • 不做 optimize-then-repair。
  • 不做 decode-time hard projection。
  • 不把 joint_angles 变成主变量。
  • 不把 root 变成逐帧离散变量。
  • 不修改老 mpc 指标定义。

11. 备注

本设计最终目标是把 mpc_qp 变成一个真正的、联合的、固定形状的 dense QP / LS 求解器：root 连续、foot 连续、joint 受控、semantic / terrain / collision / continuity / footprint 一起优化。只要结果不够好，后续只能调权重，不允许回到梯度下降或候选/repair 路线。
