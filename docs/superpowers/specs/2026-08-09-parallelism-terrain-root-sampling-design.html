Parallelism 非平地 Root 多点采样与 Viewer 调试设计

日期：2026-08-09；分支：parallelism-ladder-rl

目标与边界

在当前 Parallelism root terrain-following 逻辑上，增加前后、左右方向的多点均匀采样，使 root 的 roll/pitch 同时感知近处和远处地形。通过 viewer 调试面板调节采样范围、采样点数和已有 root 参数。

本设计只修改 root 轨迹生成和 viewer 调试接口，不修改 touchdown 候选、swing 曲线、IK、FK、collision geometry、semantic filter、score 或 RL 接口。

Flat 与 Non-flat 分流

terrain_name == "flat"
    -> 保留当前 cross-obstacles root 逻辑
    -> roll/pitch 从真实初始姿态在 root_leveling_frames 内回正

terrain_name != "flat"
    -> 使用 terrain-following root
    -> root_z 跟随地形
    -> roll/pitch 根据局部地形拟合
    -> 当局部坡度回到零附近时，roll/pitch 平滑回正

非 flat 地形不强制每条轨迹都把 roll/pitch 设为零。持续斜坡需要保留相应倾角；楼梯平台或平地段的拟合坡度接近零时，才进入回正过程。

多点 Pitch 采样

不再使用单个 pitch_sample_m。新增一个对称采样范围和采样点数：

R_pitch = terrain_following_pitch_sample_range_m
N_pitch = terrain_following_pitch_sample_count
s_i = linspace(-R_pitch, +R_pitch, N_pitch)

q_i = root_xy + s_i * forward
h_i = H(q_i)

对 (s_i, h_i) 做最小二乘直线拟合：

h(s) = k_pitch * s + b_pitch

k_pitch =
  sum((s_i - mean(s)) * (h_i - mean(h)))
  / sum((s_i - mean(s))^2)

pitch_raw = -atan(k_pitch)

使用整条采样线拟合，而不是取某两个点，可以避免采样点恰好落在同一级台阶时 pitch 变成零。

多点 Roll 采样

R_roll = terrain_following_roll_sample_range_m
N_roll = terrain_following_roll_sample_count
s_i = linspace(-R_roll, +R_roll, N_roll)

q_i = root_xy + s_i * left
h_i = H(q_i)

h(s) = k_roll * s + b_roll
roll_raw = atan(k_roll)

roll 与 pitch 使用相同的拟合、限幅、平滑和限速流程。

回正逻辑

拟合后得到的目标姿态为 roll_target 和 pitch_target。当目标角度小于 deadband 时，将目标设置为零：

if abs(roll_target) < terrain_following_rpy_deadband_rad:
    roll_target = 0

if abs(pitch_target) < terrain_following_rpy_deadband_rad:
    pitch_target = 0

然后沿现有的 smoothing 和 rate limit 逐帧跟踪。这样具有以下行为：

  • flat 或楼梯平台：采样线拟合坡度接近零，roll/pitch 回正。
  • 持续斜坡：拟合坡度非零，保留必要的地形倾角。
  • 台阶边缘：采样范围覆盖边缘时产生短暂姿态调整，经过平台后重新回正。

推荐默认参数

参数默认值含义建议调节范围
terrain_following_pitch_sample_range_m0.35前后总采样半径0.25 ~ 0.70
terrain_following_pitch_sample_count7前后方向采样点数3 ~ 9
terrain_following_roll_sample_range_m0.35左右总采样半径0.20 ~ 0.50
terrain_following_roll_sample_count5左右方向采样点数3 ~ 7
terrain_following_rpy_deadband_rad0.02小角度回正死区0.00 ~ 0.06
terrain_following_rpy_smoothing0.25姿态平滑系数0.10 ~ 0.60
terrain_following_rpy_rate_limit_rad0.03每帧姿态变化上限0.01 ~ 0.08
terrain_following_pitch_limit_rad0.35pitch 最大角度0.20 ~ 0.50
terrain_following_roll_limit_rad0.25roll 最大角度0.15 ~ 0.40

采样点数使用奇数，保证采样线中包含 root 中心点。初始推荐值为 pitch: range=0.35,count=7，roll: range=0.35,count=5。

Viewer 调试面板

在现有 Parallelism 调试面板中增加 Root Terrain 区域：

  • root clearance、root z smoothing、root z rate limit
  • pitch sample range、pitch sample count
  • roll sample range、roll sample count
  • rpy smoothing、rpy rate limit、pitch limit、roll limit
  • Reset to terrain platform 按钮

每次重新规划读取当前面板值。修改 slider 不立即改变当前已播放轨迹，下一次 replan 时生效。

Reset to Terrain Platform

面板按钮使用当前 terrain_row 和 terrain_col，把机器人传送回该 subterrain 的 origin/platform 区域。它与键盘 R 是两个独立动作：

触发方式语义适用范围
键盘 R 保留当前 viewer 的普通 reset 流程 flat 和 small obstacles
面板 Reset to terrain platform 独立的 platform teleport/reset 流程 楼梯、rough、slope、boxes 等当前选中的非 flat subterrain

面板按钮不能复用键盘 R 的 reset flag，也不能改变 R 的行为。

1. 保持当前 terrain row/col
2. root xy 传送到 selected terrain origin/platform
3. 通过 scanner 重新计算脚端贴地高度
4. 清零 root 速度和当前 command
5. 清除当前播放轨迹
6. 立即触发一次 replan

该按钮用于调参后快速恢复，不切换 terrain，不改变命令行选择的地形；普通 R 仍按原逻辑处理。

显存与计算量

多点采样只增加高度图查询，不增加 root 候选维度：

pitch 查询量: batch * horizon * pitch_sample_count
roll 查询量:  batch * horizon * roll_sample_count

默认每帧增加 12 个高度查询，仍然是 Torch GPU 并行，不会像 root trajectory bank 那样复制整条 root、IK 和 collision 张量。

基础地形泛化测试

参数选择不只针对楼梯。测试覆盖：

地形期望行为
flatroll/pitch 接近 0，并在回正帧数内稳定回正
random rough姿态变化有限，不出现 NaN 或异常跳变
slope / inverse slope能估计连续坡度，pitch 符号正确且受限幅保护
boxes局部高度变化能被感知，但姿态不被单个尖点完全决定
pyramid stairs台阶边缘有姿态调整，平台段重新回正

验收指标：

  • 所有地形输出无 NaN/Inf。
  • flat 的最终 roll/pitch 小于 0.02 rad。
  • 所有地形的 roll/pitch 不超过对应 limit。
  • 相邻帧姿态变化不超过 rate limit。
  • stairs 平台段的 roll/pitch 能回到 deadband 内。
设计阶段的高度剖面测试显示，pitch range=0.35,count=7 在 0.20 坡度上可恢复约 atan(0.20)=0.197 rad 的 pitch；在 stair edge 上触发 pitch limit；在上方平台段回到 deadband；在 boxes 边缘产生中等姿态响应，避免单个 box 过度主导 root。
