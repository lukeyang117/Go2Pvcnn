Parallelism 语义 Margin 与调试面板设计

本设计继承 2026-07-30-go2-official-surface-point-collision-design.html： Go2 leg 碰撞仍使用官方 USD collision primitive 的表面点，active leg only 与 standstill fallback 逻辑保持不变。 本次只补充 touchdown 语义 margin、调试面板速度范围、以及 show mesh 可视化开关。

1. 本次目标

  • 速度调试面板支持带方向速度，直接输出 root 坐标系下的 signed command。
  • 新增一个语义 margin 参数，只控制 touchdown 是否落在语义障碍物附近。
  • nominal candidate touchdown 与 IK 后 FK touchdown 共用同一个语义 margin。
  • show mesh checkbox 必须真正控制 IsaacSim 中 Go2 visual mesh 的可见性。
  • 不改变 official collision surface point 检测，不改变 height landing tolerance，不改变 score。

2. 速度调试面板

调试面板内的速度滑块表示 root/body frame 下的带符号速度，滑块中点为 0。

参数 范围 含义
vx [-1.0, 1.0] 前进/后退速度，正值向前，负值向后。
vy [-0.5, 0.5] 横向速度，正负方向与现有键盘 root-frame 语义一致。
vyaw [-1.0, 1.0] yaw rate，正负方向与现有键盘 yaw 语义一致。

面板只覆盖 test terminal command。键盘 teleop 的 scale 与按键映射不在本次修改范围内。 当 viewer 使用 scripted command 时，面板速度不应覆盖 scripted command，保持前一次修复后的确定性测试行为。

面板还需要提供 semantic_touchdown_margin_m 滑块。该滑块实时写入 parallelism planner config， 下一次 replan 时同时影响 nominal candidate touchdown 与 FK 后 touchdown 的语义过滤。

3. 单参数语义 Margin

新增配置项：

semantic_touchdown_margin_m: float = 0.0
字段 设计值
默认值 0.0 m，保持当前行为完全兼容。
调试面板范围 [0.0, 0.12] m。
推荐调试起点 0.03 m。在 0.01 m 语义图分辨率下，相当于约 3 个 grid cell 的外扩。
作用对象 只作用于语义 id 1 和 2 的 touchdown 过滤。
不作用对象 不影响 official collision point、高程 landing 检查、valid map、IK 关节限位和 score。

4. 语义外扩方法

语义外扩使用高分辨率 ParallelismTerrain.semantic_id，不使用 RL 后续降采样图。 先把 obstacle semantic ids (1, 2) 转成二值 mask，然后按 margin 转换出的 grid 半径做二维方形膨胀。 

radius_cells = ceil(semantic_touchdown_margin_m / terrain.resolution)
kernel_size = 2 * radius_cells + 1
expanded_obstacle = max_pool2d(obstacle_mask, kernel_size, stride=1, padding=radius_cells) > 0

touchdown 过滤时仍然只做单点查询：先把 touchdown world xy 映射到 terrain grid，再读取 expanded_obstacle[row, col]。如果为真，则该 touchdown invalid。

这个外扩是方形外扩。它比每个 touchdown 周围多点采样更快，也更容易保持 GPU 并行； 代价是边界会略保守。对于“不要踩到小障碍物附近”的需求，这个保守性是可接受的。

5. Planner 数据流

5.1 Nominal candidate touchdown

build_candidates 仍然负责生成每条腿 50 个候选点，并查询原始高度、原始语义与 valid map。 语义 hard filter 不再只看原始 candidate_semantic，而是额外用 expanded obstacle mask 检查 candidate touchdown 中心点。

5.2 FK 后 touchdown

IK 后再 FK 得到 fk_touchdown 后，继续做原有 landing height 检查。 语义 hard filter 同样查询 expanded obstacle mask；如果 FK 后真实落脚点进入外扩障碍区域，则该 candidate invalid。

5.3 Reject bits

现有 reject bit 位置保持兼容：

  • candidate_semantic reject bit：表示 nominal candidate touchdown 命中外扩语义障碍。
  • fk_touchdown_semantic reject bit：表示 FK 后真实 touchdown 命中外扩语义障碍。

diagnostics 中的 raw semantic tensor 可以继续保留，用于观察原始 touchdown 所在格子的语义 id。

6. 计算量与并行性

对于分辨率 0.01 m 的高分辨率语义图，0.03 m margin 会变成 radius_cells = 3，方形 kernel 为 7 x 7。 这一步是每次 terrain 输入后的整图 GPU 操作，之后所有 touchdown 都是单点查表。

  • 避免对每个 candidate 周围采样多个点，计算量不会随周围采样点数放大。
  • nominal 与 FK touchdown 共用同一张 expanded obstacle mask。
  • 所有条件判断使用 torch 张量逻辑，保持 env、leg、candidate 维度并行。
  • RL 后续 downsample 仍然可以独立放到 raycaster 投影后缓存，但不参与本次 planner touchdown 过滤。

7. Show Mesh 可视化开关

当前面板里的 show mesh 只更新 state，没有真正隐藏 Go2 本体。新行为需要把 checkbox 绑定到 IsaacSim visual prim 的 visibility。

状态 行为
show_mesh = true Go2 visual mesh 显示。
show_mesh = false Go2 visual mesh 隐藏，但 robot prim 不删除，planner 和关节姿态更新继续运行。

show collision body 与 show contact points 保持独立： 关闭 mesh 后仍可单独观察碰撞体中心/碰撞点，以便检查 official collision primitive 是否贴合 Go2 mesh。

8. 测试与验收

  • 单元测试覆盖 signed velocity sliders：负 vx/vy/vyaw 能进入 test terminal command。
  • 单元测试覆盖 semantic margin：中心点原始语义为 0，但进入外扩区域时被 hard reject。
  • 单元测试分别覆盖 nominal candidate 与 FK touchdown 两个语义 reject bit。
  • viewer 测试需要证明调试面板能打开，速度滑块改变 planner command，semantic_touchdown_margin_m 能进入 ParallelismCfg。
  • IsaacSim 目视验收：关闭 show mesh 后 Go2 本体消失；碰撞点和碰撞体开关仍独立生效。

9. 不做的事

  • 不把 planner touchdown 过滤切到低分辨率 RL semantic map。
  • 不在 observation 中迁移 downsample 逻辑。
  • 不改变 score，仍只用速度跟踪位移误差。
  • 不改变 root 搜索、trot 周期、active-leg-only 碰撞边界。
  • 不复用 joint_mpc_rti 代码。
