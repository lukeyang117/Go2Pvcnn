M1 Parallelism 机器人后端设计

在保持 Go2 默认行为不变的前提下，为轮式机器狗 M1 增加独立运动学、关节映射、地形策略和腿部碰撞几何。

设计摘要

12 DOF Parallelism 只规划 ABAD、HIP、KNEE
4 wheels 轮轴关节完全不进入规划参考
16 shapes 四腿与轮子碰撞体，不检测 BASE
0.6358 m M1 零位姿轮底贴地 Root 高度

边界与确认决策

统一 PlannerGo2 与 M1 共用候选、步态、地形查询和轨迹结构。
后端隔离关节映射、FK、IK、限位与碰撞几何由 robot backend 提供。
Go2 默认兼容未传 --robot、直接构造 ParallelismCfg() 都继续表示 Go2。
轮轴不受关注M1 四个 FOOT_JOINT 不输入、不输出，也不参与限位检查。
保持对角相位继续使用当前 24 帧与 diagonal trot 相位，不重新设计 gait。
平地滚动参考flat 垂向 apex 为零；非平地或小障碍物才抬腿。
大障碍绕行沿用当前横向绕行，不尝试抬腿跨越大障碍。
不检测 BASE与 Go2 当前边界一致，Parallelism 只做腿部和脚端几何碰撞。
范围外：RL policy、奖励、动作空间、轮子转速参考、self-collision 和 M1 Isaac Lab 资产配置的完整实现。

对称化规则：忽略 FBL link frame 中约 0.01° 的 X 轴导入误差；前后仅改变 X 符号，左右仅改变 Y 符号，所有同类 link 使用相同尺寸。

默认站姿

USD 中 16 个关节的 targetPosition 均为 0°。M1 的 12 DOF neutral_joint_pos 定义为全零。

M1 FK / IK

Root transform → BASE-to-ABAD translation → RotX(ABAD) → ABAD-to-HIP translation → RotY(HIP) → HIP-to-KNEE translation → RotY(KNEE) → KNEE-to-wheel-center translation

FK 输出

  • 四个轮轴中心世界位置
  • ABAD、HIP、KNEE 和 wheel link frame
  • 碰撞 primitive 的世界坐标变换
  • 不读取或依赖轮轴角度

IK 判定

  • 输入 Root pose 与四个轮心目标
  • 返回 12 DOF 和 reachable mask
  • 不可达、越限、非有限值均拒绝候选
  • 同主评分候选优先接近零位姿

Go2 隔离要求：fk_go2()、ik_go2() 和现有 Go2 数值保持原样，由 Go2 backend 包装调用，不把 M1 分支写入公式内部。

碰撞近似与碰撞点

轮底接触容忍

只有圆周角 θ=270°、位于三层宽度上的三个轮底点可以容忍普通地形接触。必须同时满足：

contact_state == True AND point_role == wheel_bottom_support AND semantic_id NOT IN {small_obstacle, large_obstacle}

摆动帧、轮子前后/侧面/顶部，以及任何命中语义障碍物的点都正常判碰撞。碰撞条件沿用：

terrain_height >= point_world_z - collision_margin_m
明确边界：不生成 BASE primitive，不输出 BASE collision bit，不做机器人 link 间 self-collision。大障碍物继续由现有横向绕行逻辑处理。

Root Z 跟随地形；RPY 使用低频过滤，smoothing 为 0.90，roll/pitch 上限均为 0.12 rad。

验证与回归策略

Go2 零回归

  • 原 FK、IK 和配置数值不变
  • 无参数与 --robot go2 等价
  • 固定输入 trajectory tensor 一致
  • 现有 Parallelism 测试全部通过

M1 单元验证

  • 16 → 12 DOF 任意顺序映射
  • 零位姿 FK 与 USD 几何一致
  • FK → IK → FK 闭环
  • 左右 ABAD 限位正确
  • 轮轴不进入输出

碰撞与地形

  • Box 26 点、wheel 38 点精确生成
  • 仅三个轮底点可容忍支撑
  • BASE shape 数量严格为零
  • 20 列 terrain profile 精确映射
  • 各 terrain family 仿真 smoke
验收标准：M1 能产生现有 schema 的有效 12 DOF 轨迹；flat 不主动抬腿，非平地按 profile 抬腿；轮底能支撑，轮子前侧撞障碍会拒绝候选；Go2 默认命令与改造前一致。
