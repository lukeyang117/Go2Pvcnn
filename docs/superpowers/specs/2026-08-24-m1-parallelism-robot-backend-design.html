M1 Parallelism 机器人后端设计

在保持 Go2 默认行为不变的前提下，为轮式机器狗 M1 增加独立运动学、关节映射、地形策略和腿部碰撞几何。

设计摘要 边界与决策 总体架构 USD 几何 FK / IK 碰撞近似 地形策略 数据流 文件结构 Isaac Sim Viewer 验证策略

设计摘要

12 DOF Parallelism 只规划 ABAD、HIP、KNEE
4 wheels 轮轴关节完全不进入规划参考
16 shapes 四腿与轮子碰撞体，不检测 BASE
0.6358 m M1 零位姿轮底贴地 Root 高度

边界与确认决策

统一 PlannerGo2 与 M1 共用候选、步态、地形查询和轨迹结构。
后端隔离关节映射、FK、IK、限位与碰撞几何由 robot backend 提供。
Go2 默认兼容未传 --robot、直接构造 ParallelismCfg() 都继续表示 Go2。
轮轴不受关注M1 四个 FOOT_JOINT 不输入、不输出，也不参与限位检查。
保持对角相位继续使用当前 24 帧与 diagonal trot 相位，不重新设计 gait。
平地滚动参考flat 垂向 apex 为零；非平地或小障碍物才抬腿。
大障碍绕行沿用当前横向绕行，不尝试抬腿跨越大障碍。
不检测 BASE与 Go2 当前边界一致，Parallelism 只做腿部和脚端几何碰撞。
Viewer 选择资产go2_foostep_planner.py 根据 --robot 选择 USD、环境配置和 backend。
Isaac Sim 验证第一阶段使用运动学直接回放，验证规划、几何、碰撞点和参数，不接入 RL。
范围外：RL policy、训练奖励、正式动作空间、轮子转速参考、self-collision，以及面向物理控制/训练的 M1 actuator 调参与完整任务配置。

M1 USD 几何提取

参数来自 m1/ZJ_V3_URDF_V1_0/ZJ_V3_URDF_V1_0.usd。USD 是 composed binary crate，运行时不读取约 116 MB 的 Mesh；所需值离线提取后写入 M1 静态配置。

默认站姿

USD 中 16 个关节的 targetPosition 均为 0°。M1 的 12 DOF neutral_joint_pos 定义为全零。

Root 到轮心为 0.5398 m，轮半径为 0.095958 m，平地目标高度取 0.6358 m。

M1 FK / IK

Root transform → BASE-to-ABAD translation → RotX(ABAD) → ABAD-to-HIP translation → RotY(HIP) → HIP-to-KNEE translation → RotY(KNEE) → KNEE-to-wheel-center translation

FK 输出

  • 四个轮轴中心世界位置
  • ABAD、HIP、KNEE 和 wheel link frame
  • 碰撞 primitive 的世界坐标变换
  • 不读取或依赖轮轴角度

IK 判定

  • 输入 Root pose 与四个轮心目标
  • 返回 12 DOF 和 reachable mask
  • 不可达、越限、非有限值均拒绝候选
  • 同主评分候选优先接近零位姿

Go2 隔离要求：fk_go2()、ik_go2() 和现有 Go2 数值保持原样，由 Go2 backend 包装调用，不把 M1 分支写入公式内部。

碰撞近似与碰撞点

M1 沿用 Go2 的“静态 primitive → 固定表面点 → FK 变换 → terrain height 查询”结构。不同点在于 M1 的 box 和 wheel 使用更密的固定采样，且完全不建立 BASE shape。

轮底接触容忍

只有圆周角 θ=270°、位于三层宽度上的三个轮底点可以容忍普通地形接触。必须同时满足：

contact_state == True AND point_role == wheel_bottom_support AND semantic_id NOT IN {small_obstacle, large_obstacle}

摆动帧、轮子前后/侧面/顶部，以及任何命中语义障碍物的点都正常判碰撞。碰撞条件沿用：

terrain_height >= point_world_z - collision_margin_m
明确边界：不生成 BASE primitive，不输出 BASE collision bit，不做机器人 link 间 self-collision。大障碍物继续由现有横向绕行逻辑处理。

M1 ArticulationCfg

M1_CFG 参考 UNITREE_GO2_CFG 的 Isaac Lab 配置结构，但机器人参数取自 M1 USD，不复制 Go2 的关节初值和 actuator 数值。

复用 Go2 配置结构

  • UsdFileCfg 和 contact sensor 启用方式
  • 关闭 articulation self-collision
  • solver iteration 和刚体速度限制的配置形式
  • soft_joint_pos_limit_factor=0.9

M1 必须覆盖

  • USD 路径与 Root 初始高度 0.6358 m
  • 16 个关节初值和速度均为零
  • ABAD/HIP/KNEE 与 wheel 的 actuator 分组
  • 关节、BASE 和 support body 名称
第一阶段限制：Viewer 使用当前的运动学直接回放路径，不通过 actuator 跟踪轨迹。Actuator 配置只需保证 Isaac Lab articulation 能正确实例化和完成 warmup；正式物理控制参数不在本设计范围内。

M1 Viewer 专用环境配置

不能仅替换 env_cfg.scene.robot.spawn.usd_path。现有 PLAY 配置还包含 Go2 的 scanner attachment、.*_foot body selector、base selector和 12 DOF tracking term。M1 viewer 配置继承现有 terrain generator、语义障碍和 scanner 参数，并完成以下替换：
