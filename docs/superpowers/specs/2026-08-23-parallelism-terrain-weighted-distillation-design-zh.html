Parallelism 按地形难度加权蒸馏

目标：让学生继承新教师跨越小障碍物和绕开大障碍物的能力，同时由 PPO 在复杂地形上自主学习并超过教师。

核心决定

所有环境始终执行 student action。teacher 仅生成 deterministic imitation target，不再接管 IsaacSim。脚本中的实际初始 imitation 系数为 teacher_coef=0.1；复杂地形的系数随各自课程难度下降，两个 flat 地形保持 0.1。规划无效时 imitation 梯度必须严格为零。

一、训练目标与边界

学生需要保留的能力

  • 在 flat_dense_small_obstacles 上跨越密集小障碍物。
  • 根据语义地图识别并绕开大障碍物。
  • 在 random_rough、正反斜坡、boxes、正反楼梯上通过 PPO 自主学习稳定行走。
  • 复杂地形难度升高后，逐步降低弱教师对 student actor 的约束。

学生观测

学生继续保留当前 16×16 高程图、语义地图、速度指令和本体状态；不输入 Parallelism reference trajectory，也不恢复已删除的 base_lin_vel。高程和语义输入是学生在新位置泛化跨越与绕行行为的必要信息。

二、目标数据流

Student高程图、语义图、command、本体状态，生成带 std 的动作。
Teacher特权 reference 与 plan valid，生成 detached action target。
Critic独立 privileged observation，估计 PPO value。
Context地形类型、难度和 plan valid，生成 imitation multiplier。
student_obs[t] ──> student actor ──> sampled student_action[t] ──> IsaacSim
teacher_obs[t] ──> frozen teacher ─> deterministic teacher_action[t]
critic_obs[t]  ──> student critic ─> value[t]
terrain context ──────────────────> imitation_multiplier[t]

transition[t] 同时保存以上数据，update 时不重新查询地形状态。

权重必须在采集当前 transition 时计算和保存。环境 reset 或课程更新后，只影响新 transition，不能反向改变 rollout buffer 中旧样本的权重。

三、地形与难度权重

全局系数

训练脚本显式设置：

--ppo-coef 1.0
--teacher-coef 0.1
--teacher-ratio-start 0.0
--teacher-ratio-end 0.0

teacher_coef=0.1 是所有地形在 Level 0 时最终进入总 loss 的实际 imitation 系数，不再进行全局时间衰减。

难度归一化

当前地形配置有 10 行课程难度，terrain_level 的范围为 0 到 9：

d_i = clamp(terrain_level_i / 9, 0, 1)

每种地形的倍率为：

multiplier_t(d) = end_t + (1 - end_t) * (1 - d) ^ power_t

power 越大，前中期下降越快。flat 地形通过 end=1 保持不变。

未知地形规则

如果无法解析地形列、地形名称不在配置表中，或者缺少课程等级，imitation multiplier 返回 0。未知状态只能关闭教师监督，不能默认信任教师。

四、Plan Invalid 的严格零梯度契约

对第 i 个样本，先计算 12 维动作的逐样本均方误差：

sample_mse_i = mean_j((student_mean_ij - teacher_action_ij) ^ 2)

定义二值有效性掩码和最终倍率：

valid_i      = float(parallelism_plan_valid_i)       # 只允许 0 或 1
weight_i     = terrain_multiplier_i * valid_i
effective_i  = teacher_coef * weight_i

最终 imitation loss 使用普通 batch mean：

weighted_imitation_loss = mean_i(weight_i * sample_mse_i)
total_loss = ppo_coef * ppo_loss + teacher_coef * weighted_imitation_loss
硬性验收条件

当 plan_valid_i=0 时，该样本对 student actor 的 imitation 梯度必须严格等于 0：

d L_imitation / d student_mean_ij
  = teacher_coef * weight_i * 2 * (student_mean_ij - teacher_action_ij) / (B * 12)
  = 0,  when plan_valid_i = 0

PPO 梯度不受该 mask 影响；invalid 样本仍然是正常的 on-policy PPO 数据。

全 minibatch invalid

当整个 minibatch 都 invalid 时，不能使用“除以有效权重总和”的归一化，也不能回退到 unweighted MSE。实现应保留计算图：

weighted_imitation_loss = (sample_mse * zero_weight).mean()

该标量数值为有限的精确 0，且对 student actor 的 imitation 梯度为精确 0，不产生除零或 NaN。

五、优化器稳定性

继续使用当前 Adam、learning_rate=3e-4 和 max_grad_norm=1.0。不新增优化器，也不修改 PPO 学习率。

  • 权重范围有界，实际 imitation 系数始终位于 [0, 0.1]。
  • 每次 rollout 约有 1024 × 40 = 40960 个样本，每个 minibatch 约 10240 个样本，地形混合后的权重均值稳定。
  • 地形课程只在环境 reset 时变化；异步 reset 使整个 batch 的权重分布逐渐变化。
  • 同一 transition 的权重在 5 个 PPO epoch 中保持不变。

风险主要是早期 imitation 对 actor 更新的相对影响，而不是数值发散。通过 TensorBoard 同时观察 PPO surrogate 和实际 imitation contribution 判断是否需要降低全局 0.1。

七、TensorBoard 指标

  • Distillation/teacher_coef：固定为 0.1。
  • Distillation/effective_teacher_coef_mean：当前 batch 的实际平均系数。
  • Distillation/effective_teacher_coef/<terrain>：各地形实际平均系数。
  • Distillation/plan_valid_ratio：可参与 imitation 的样本比例。
  • Distillation/imitation_loss_unweighted：仅用于判断 student 与 teacher 的原始差距。
  • Distillation/imitation_loss_weighted：乘地形与 valid mask 后、尚未乘 0.1 的 loss。
  • Distillation/imitation_contribution：实际加入总 loss 的 0.1 × weighted loss。
  • Distillation/imitation_to_surrogate_ratio：按 abs(imitation_contribution) / (abs(surrogate_loss) + 1e-6) 计算，判断 imitation 是否长期压过 PPO actor 更新。
  • Distillation/ppo_active_ratio：应始终等于 1。

八、验证方案

纯 Torch 单元测试

  • 验证所有地形 Level 0 的实际系数均为 0.1。
  • 验证两个 flat 地形在 Level 0 到 9 始终为 0.1。
  • 验证复杂地形权重单调下降，并精确到达表中 Level 9 端点。
  • 验证 generated terrain 的 20 个 column 正确映射到 8 个地形 family。
  • 构造 valid/invalid 混合 batch，通过 autograd 验证 invalid 样本 imitation 梯度逐元素严格为 0。
  • 构造全 invalid minibatch，验证 loss 有限且等于 0，student imitation 梯度严格为 0。
  • 验证 invalid mask 只屏蔽 imitation，不屏蔽 PPO loss。

配置与 checkpoint 测试

  • 验证新 teacher actor 输入为 1103，并能加载 model_9899.pt。
  • 验证 student 与 critic 输入维度不因 teacher 增加 plan-valid 而变化。
  • 验证环境实际执行动作全部来自 student，ppo_active_ratio=1。
  • 验证非蒸馏 PPO 和旧 teacher 训练路径不读取 imitation_weights，行为保持不变。

真实 IsaacSim 启动测试

  • 使用新教师启动 1024 环境，运行 4 iterations。
  • 确认无 checkpoint 维度错误、rollout 字段错误、NaN 或 CUDA shape 错误。
  • 确认 TensorBoard 产生逐地形权重、weighted imitation 和 plan-valid 指标。
  • 确认存在 invalid planner 样本时，imitation contribution 按有效样本下降，而 PPO 仍持续更新。

九、明确不修改

  • 不修改 Parallelism planner、23 控制步重规划周期、reference 时间戳和 reset 逻辑。
  • 不修改地形生成、地形课程更新条件、速度课程、reward 和 termination。
  • 不让 teacher action 进入 IsaacSim，不使用 teacher ratio 调度。
  • 不删除学生的高程图和语义地图。
  • 不让 invalid teacher target 通过任何 fallback 产生 imitation 梯度。
  • 不修改普通 PPO 与非蒸馏 teacher 的训练配置。
Fresh training 边界

本设计默认使用新 teacher 启动一轮新的 student 训练。现有 resume checkpoint 的迁移不属于本次设计；若后续 resume，仍需显式提供 teacher checkpoint，并由已有加载规则保证新 teacher 覆盖 checkpoint 内嵌 teacher。

最终验收核心

plan_valid=0 不等于“教师 loss 很小”，而是该样本的 imitation 梯度数学上严格为零；同时该样本仍完整参与 PPO。这个条件必须由 autograd 单元测试验证，不能只通过 TensorBoard 数值推断。
