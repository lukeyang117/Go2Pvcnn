Parallelism Small Obstacles RL 设计

本设计用于在当前 parallelism-small-obstacles-rl 分支上新增一个 parallelism_tracking_small_obstacles 强化学习任务。第一版目标是复用当前 Parallelism planner 和平地 RL tracking 配置，在固定局部小障碍场景中训练 Go2 学会全向跨越 small obstacles。

1. 目标和非目标

目标

  • 训练 policy 在一个固定的局部 small-obstacle 场景中，跟随 Parallelism reference 持续跨越小障碍物。
  • 速度指令保留当前平地任务的课程学习，从低速逐步扩展到 viewer 的完整速度范围。
  • 障碍物场景不做难度课程，第一版只验证固定难度下是否能学会 crossing。
  • 新增 obstacle 相关 reward 和 metric，帮助判断足端是否安全踩到 small obstacle，以及几何碰撞是否降低。
  • 训练和 play 都使用独立 experiment 名，日志独立保存，避免污染平地任务。

非目标

  • 不修改 Parallelism planner 的 touchdown 采样、IK、FK、standstill 核心逻辑。
  • 不做 10 个不同 layout，也不做 area-center 引导速度。
  • 不使用 Isaac Sim 真实 contact sensor 作为小障碍碰撞 reward 的主要依据。
  • 不因为 Parallelism 几何碰撞立即 reset。
  • 不引入 large obstacles。

3. 唯一场景和唯一 subterrain 设计

本任务不是定义一个场景后，再复制成多个不同的 subterrain，也不是创建多个难度场景。 第一版只有一个场景、一个 subterrain：small_obstacles。 所有训练环境共享这一个固定的 subterrain 布局。 terrain tile 仍然使用平地底面，small obstacles 只放在 reset 中心附近的一个局部正方形区域。 这个区域中间挖掉一个圆形安全区，保证机器人 reset 后初始 root 和四足站姿不会直接被障碍物干扰。 

terrain_generator
└── sub_terrains
    └── small_obstacles   # 唯一 subterrain，唯一固定布局

num_rows = 1
num_cols = 1

所有 env
└── 共享同一个 small_obstacles 场景布局

这里的“一个场景”指一个固定的地形生成实例和一个固定的障碍物布局。 不使用 terrain curriculum，不创建多个 row/column 难度等级，不按 scene id 给环境分配不同布局。 1024 个环境只是复制物理环境来并行训练，它们面对的是同一个 subterrain 内容。 

俯视图：

  obstacle patch: 2.0m x 2.0m

  +-----------------------------+
  |  x    x    x    x    x      |
  |     x    x    x    x    x   |
  |  x    x           x    x    |
  |     x       O       x       |
  |  x    x           x    x    |
  |     x    x    x    x    x   |
  |  x    x    x    x    x      |
  +-----------------------------+

  x = small obstacle
  O = reset 圆形安全区

第一版场景参数

参数 建议值 含义
obstacle_patch_size_m 2.0 局部小障碍正方形区域边长，区域中心与 robot reset 中心对齐。
reset_clear_radius_m 0.25 语义上的 reset 安全圆半径，希望这个圆内保持无障碍。
obstacle_center_exclusion_radius_m 0.30 生成障碍物中心点时的排除半径，约等于安全圆半径加障碍物半宽。
small_obstacle_count 24 第一版小障碍物数量。若 planner standstill 高，可降到 16 或 20；若太稀，可升到 32 或 40。
small_obstacle_jitter_m 0.03 均匀网格点上的轻微扰动，避免过于机械的排列。
small_obstacle_min_spacing_m 0.18 障碍物中心之间的最小间距，防止局部完全堵死。
large_obstacle_count 0 第一版不加入 large obstacles。
semantic_touchdown_margin_m 0.12 沿用当前 Parallelism 默认值，用于 touchdown 语义外扩过滤。
reset_clear_radius_m 与 obstacle_center_exclusion_radius_m 的区别： reset_clear_radius_m 表示最终想空出来的真实安全圆； obstacle_center_exclusion_radius_m 表示撒障碍物中心时的禁区。因为障碍物有宽度，中心点排除半径需要比安全圆略大。

障碍物分布方法

  • 在 2.0m x 2.0m patch 内生成均匀网格。
  • 删除落入中心圆排除半径 0.30m 的网格点。
  • 从剩余点中选择 24 个中心点。
  • 对每个中心点加入 ±0.03m 的小扰动。
  • 检查障碍物中心间距不小于 0.18m。
  • shape 可以轮换或固定随机种子生成，但场景初始化后不刷新。

4. 速度指令设计

速度指令不再根据 obstacle area center 引导，而是保持平地任务的 root 坐标系随机速度课程。 这样 policy 会在同一个局部小障碍场景中学习前进、后退、横移、斜向和转向 crossing。

采样范围

阶段 vx vy vyaw
初始课程 [-0.1, 0.1] [-0.05, 0.05] [-0.2, 0.2]
最终范围 [-1.0, 1.0] [-0.5, 0.5] [-1.0, 1.0]
  • 不增加最小平移速度过滤，不要求 sqrt(vx^2 + vy^2) > v_min。
  • 速度重采样周期保持 0.48s，对齐 Parallelism 24 帧轨迹。
  • 课程只放宽升级阈值，不改变采样逻辑。
  • rel_standing_envs 第一版可沿用 flat 默认值，除非训练中出现 standing 样本过多。

课程阈值

课程仍然使用当前 Parallelism tracking 的 velocity curriculum，但 small-obstacles 任务需要放宽升级条件， 避免固定障碍场景导致课程长期停在低速。

指标 flat 当前参考 small obstacles 第一版建议
root_pos_threshold 0.12 0.18
root_rot_threshold 0.30 0.45
joint_mean_threshold 0.22 0.32
joint_max_threshold 0.8 1.0

5. Reward 设计

新任务继承 flat 的 reference tracking reward，并新增两个小障碍相关 reward。

保留的 tracking reward

  • track_root_pos
  • track_root_rot
  • reference_joint_pos
  • reference_joint_vel
  • reference_foot_pos
  • reference_active_swing_foot_max
  • reference_joint_max
  • 现有 locomotion regularization，例如 action rate、joint velocity、torque、orientation 等。

新增 reward 1：Parallelism 几何碰撞惩罚

Penalty parallelism_geometry_collision_penalty

  • 使用 Parallelism planner 的几何碰撞检测逻辑，而不是 Isaac Sim 真实接触传感器。
  • 基于当前 policy 的关节状态、足端状态、semantic/elevation map，检测 active swing leg 的 thigh、calf、foot 几何点是否进入高程障碍物。
  • 输出每个 env 的 collision mask 或 collision count。
  • 发生碰撞只扣 reward，不触发 reset。
  • 实现必须使用 Torch 张量条件判断，保持 GPU 并行。

新增 reward 2：active swing 足端踩 small obstacle 奖励

Reward active_swing_foot_on_small_obstacle_reward

  • 只看当前 active swing 足端，不奖励所有 stance 足端。
  • 查询 active swing foot 当前世界坐标对应的 semantic map。
  • 如果 semantic id 是 small obstacle，并且该腿没有 Parallelism 几何碰撞，则给正奖励。
  • 这个 reward 鼓励“安全踩上 small obstacle”，不是鼓励真实物理碰撞。

第一版建议权重

Reward 建议权重 备注
parallelism_geometry_collision_penalty -1.0 先中等强度惩罚，避免一碰就完全压制探索。
active_swing_foot_on_small_obstacle_reward 0.5 辅助奖励，不能大到超过 tracking 主目标。

6. Termination 设计

不新增小障碍几何碰撞 reset。保留 flat 当前 termination：

  • time_out
  • base_contact
  • bad_orientation
  • parallelism_ref_root_z_too_far
  • parallelism_ref_projected_gravity_too_far
  • parallelism_ref_foot_z_too_far
  • parallelism_ref_joint_pos_too_far
第一版碰撞策略：Parallelism 几何碰撞只作为 reward penalty，不作为 termination。 这样 policy 即使出现不完美跨越，也有机会继续恢复和学习。

7. Metric 设计

新增 obstacle 相关 episode 指标，方便从 TensorBoard 判断训练是否真正学到了跨障碍。

Metric 含义
Episode_Obstacle/geometry_collision_ratio Parallelism 几何碰撞发生比例。
Episode_Obstacle/active_swing_foot_on_small_ratio active swing 足端踩到 small obstacle 的比例。
Episode_Obstacle/active_swing_foot_on_small_no_collision_ratio active swing 足端踩到 small obstacle 且无几何碰撞的比例。
Episode_Obstacle/standstill_ratio Parallelism reference 进入 standstill 的比例。
Episode_Obstacle/reference_valid_ratio Parallelism 规划出有效 reference 的比例。

继续保留现有 tracking 指标，例如：

  • Episode_Tracking/episode_joint_mean_error
  • Episode_Tracking/episode_joint_max_error
  • Episode_Tracking/episode_reference_root_pos_error
  • Episode_Tracking/episode_reference_root_rot_error
  • Episode_Tracking/episode_reference_foot_mean_error
  • Episode_Tracking/episode_reference_active_foot_max_error

训练

Go2Pvcnn/scripts/train.py \
  --experiment parallelism_tracking_small_obstacles \
  --num_envs 1024 \
  --device cuda:0 \
  --headless

日志目录：

logs/rsl_rl/parallelism_tracking_small_obstacles/

Play

Go2Pvcnn/scripts/play.py \
  --experiment parallelism_tracking_small_obstacles \
  --run_dir <date/hash> \
  --checkpoint <checkpoint> \
  --num_envs 1 \
  --device cuda:0

PLAY 配置继承 flat 的可视化能力：

  • 淡蓝 reference Go2。
  • policy Go2。
  • 速度调试面板。
  • termination 勾选控制。
  • 小障碍固定场景。

9. 验证要求

  • 配置导入测试：新 experiment 可以被 train.py 和 play.py 识别。
  • 短训练 smoke test：1024 env，至少 4 iteration，确认 epoch 计数增加且无崩溃。
  • 场景验证：semantic/elevation map 中出现中心局部 small obstacles，中心 reset 安全区无障碍。
  • Planner 验证：Parallelism reference 能在该场景中持续输出，不应大量 standstill。
  • Reward 验证：新增 obstacle reward 和 metric 在 TensorBoard 中有非零输出。
  • Play 验证：加载 checkpoint 后，reference 和 policy 能在固定小障碍场景中可视化。

10. 第一版调参判断

现象 优先调整
standstill_ratio 高 降低 small_obstacle_count 到 16 或 20，或放宽 planner touchdown 过滤。
geometry_collision_ratio 高 提高 parallelism_geometry_collision_penalty 权重，或降低障碍物密度。
active_swing_foot_on_small_ratio 很低 提高 active_swing_foot_on_small_obstacle_reward 权重，或增加障碍物密度。
tracking 明显变差 提高 reference foot/joint reward，或先降低速度课程升级速度。
训练长期停在低速课程 继续放宽课程阈值，尤其 joint_mean_threshold 和 joint_max_threshold。

11. 最终决策

第一版采用一个固定小型场景：中心 2.0m x 2.0m small-obstacle patch， 中间 0.25m reset 安全圆，障碍物中心排除半径 0.30m， 默认 24 个 small obstacles，速度保持 flat 的课程随机采样。 新任务单独建文件并注册为 parallelism_tracking_small_obstacles。
