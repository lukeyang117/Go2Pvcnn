Parallelism Distillation DAgger V2 设计

日期：2026-08-16　 分支：parallelism-large-obstacles-distillation-rl　 目标 experiment：parallelism_tracking_cross_large_complex_distillation

1. 目标

在不影响原 parallelism_tracking_cross_large_complex PPO 训练的前提下， 给蒸馏实验加一个更保守的 DAgger 风格 teacher ratio 课程。前期完全由 teacher 控制， 中期 teacher/student 混合，后期再切到 student。

这是一版单独的新设计，不修改旧的 distillation spec。

2. 核心决策

  • 不使用 action std。
  • 不引入 PPO 梯度。
  • teacher 只提供监督标签。
  • 环境执行 action 由 teacher/student 按比例切换。
  • teacher_ratio 只从命令行参数的 max_iterations 和当前 iteration 计算。

3. teacher_ratio 课程

这版比旧设计更保守，衰减更慢。推荐： 

progress = iteration / max_iterations
if progress < warmup_pct:
    teacher_ratio = 1.0
elif progress < decay_end_pct:
    teacher_ratio = 1.0 - (progress - warmup_pct) / (decay_end_pct - warmup_pct)
else:
    teacher_ratio = teacher_ratio_min
参数值含义
warmup_pct0.10前 10% iteration 全 teacher。
decay_end_pct0.80从 10% 线性衰减到 80%，更慢让 student 接管。
teacher_ratio_min0.080% 之后完全 student。

环境执行策略：

mask = rand(num_envs) < teacher_ratio
env_action = where(mask, teacher_action, student_action)
target_action = teacher_action

不采用 teacher_action 与 student_action 的数值线性平均， 因为那会破坏摆腿节奏和落脚时序。

4. 文件边界

文件作用
agent/train_cfg.py仅为 distillation experiment 增加 teacher_ratio schedule 配置。
rsl_rl/rsl_rl/algorithms/distillation.py读取 teacher_ratio，决定环境执行 teacher 还是 student action。
rsl_rl/rsl_rl/modules/student_teacher_cnn.py保留 CNN teacher/student 结构，不改 PPO 代码路径。
scripts/train.py只在 distillation experiment 中读取 teacher checkpoint 和 schedule。
scripts/play.py继续只用 student 做 inference。
tracking/parallelism_cross_large_complex_distillation_env_cfg.py只承载蒸馏 observation 分组，不影响原 PPO 环境。

5. 风险控制

  • teacher_ratio 衰减慢，可以减少学生过早接管导致的短 episode。
  • 原 PPO 训练路径不读取 teacher_ratio，因此不会被污染。
  • 若后续要接 PPO 梯度，可以在蒸馏 experiment 内单独扩展，不影响旧实验。

6. 测试要求

  • 静态测试：确认新 schedule 字段出现在 distillation 配置中。
  • 训练 smoke：1024 环境跑 4 iteration，确认 teacher_ratio 被写入 TensorBoard。
  • 兼容性：原 PPO experiment 配置和命令行参数不变。
