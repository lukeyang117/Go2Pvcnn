Parallelism 官方线速度课程设计

适用任务：parallelism_tracking_cross_large_complex_distillation

版本日期：2026-08-17

一、最终结论

关闭 Parallelism 自定义的 reference tracking 速度课程，改用 Go2Pvcnn 的 reward-based 线速度课程。课程只调整 lin_vel_x 和 lin_vel_y，不调整 yaw。

  • ang_vel_z 直接固定随机范围 [-1.0, 1.0]。
  • yaw 不参与课程升级，不从小范围逐级扩大。
  • 最新 reward 权重和 std 全部保留，不重新调权重。
  • student 不输入当前真实 base_lin_vel，仍只输入速度命令。

二、修改边界

模块处理方式
student observation保持 reference-free，只保留 command、角速度、姿态、关节和地形观测。
teacher observation保留 reference trajectory 和特权状态。
critic observation保留 privileged state、reference 和真实速度。
速度 reward保留最新的线速度、yaw 角速度奖励及其权重。
速度 curriculum删除 reference error 门槛，换成 Go2Pvcnn 风格的线速度 reward 门槛。
yaw command固定为 [-1.0, 1.0]，不参与 curriculum。
terrain curriculum保持现有地形课程，和速度课程独立运行。
distillation / PPO不改变 teacher/student episode 分配和 loss 结构。

三、Observation 设计

Student policy 输入

  • semantic elevation map
  • base_ang_vel
  • projected_gravity
  • relative joint position
  • relative joint velocity
  • velocity_commands
  • last action

student 不输入 base_lin_vel，不输入 Parallelism reference trajectory。

Teacher / critic 输入

  • student 可见的地形和本体状态
  • 真实 base_lin_vel
  • 真实 base_ang_vel
  • Parallelism reference joint/root 状态
  • velocity command
  • last action

critic 保留特权输入，不改变 PPO value 学习所需的信息。

速度命令统一通过 generated_commands(command_name="base_velocity") 读取，内容为： 

[lin_vel_x_command, lin_vel_y_command, ang_vel_z_command]

四、Command 范围

命令初始范围课程上限是否课程扩大
lin_vel_x[-0.1, 0.1] m/s[-1.0, 1.0] m/s是
lin_vel_y[-0.05, 0.05] m/s[-0.5, 0.5] m/s是
ang_vel_z[-1.0, 1.0] rad/s[-1.0, 1.0] rad/s否，启动即使用完整范围

yaw 直接使用完整范围。它的 reward 仍然训练策略跟踪 yaw command， 但 yaw 不会触发任何课程更新。

五、Reward 设计

Reward函数当前权重std用途
track_lin_vel_xy track_lin_vel_xy_exp 2.0 0.5 PPO reward，同时驱动线速度课程
track_ang_vel_z track_ang_vel_z_exp 1.5 0.5 PPO reward，只用于 yaw 跟踪，不驱动课程

其他 joint、foot、root、collision、energy 和 action regularization reward 全部保留现有最新配置。

六、线速度 Curriculum

使用 Go2Pvcnn 的 lin_vel_cmd_levels 逻辑，不再使用 root_pos_threshold、root_rot_threshold、 joint_mean_threshold 和 joint_max_threshold。

统计一个 episode 的 track_lin_vel_xy 加权 reward
除以 episode 时长，得到平均线速度跟踪 reward
与 track_lin_vel_xy.weight × 0.8 比较
达标后同时扩大 lin_vel_x 和 lin_vel_y
使用 limit range 做 clamp，达到上限后不再扩大

当前线速度 reward 权重为 2.0，因此升级参考阈值为：

mean_track_lin_vel_xy_reward > 2.0 × 0.8 = 1.6

每次升级的步长保持 Go2Pvcnn 逻辑： [-0.1, 0.1] 的对称增量，分别作用到 x、y 两个线速度范围。

与当前 Parallelism curriculum 不同，官方风格课程只在 reward 达标时扩大范围， 不因为 reference tracking 误差或 termination 自动回退速度范围。

七、Yaw 处理

固定完整范围

ang_vel_z ∼ Uniform(-1.0, 1.0)
  • 启动时就使用完整 yaw command 范围。
  • 不设置 yaw level。
  • 不使用 track_ang_vel_z reward 更新 command range。
  • yaw reward 仍然参与 PPO 和 teacher/student 行为学习。

八、地形课程与速度课程的关系

线速度课程：只由 track_lin_vel_xy reward 扩大 vx/vy
地形课程：由实际行走距离、地形成功条件和语义障碍条件更新 terrain level
Reference tracking：只用于 reward、termination、metric 和蒸馏，不再控制速度范围

这样可以避免 teacher/student 混合 episode 中，reference tracking 误差直接影响速度课程， 也避免 yaw 范围在训练中二次变化。

九、Command 到 Parallelism Planner 的接口

课程更新不能只修改 IsaacLab command 的范围，也必须保证最新 command 在下一次规划时进入 Parallelism。command 的唯一来源是环境的 command_manager。

base_velocity command manager 生成当前环境的三维命令
student observation 读取同一个 command tensor
ParallelismReferenceManager 在每次重规划时重新读取 get_command("base_velocity")
截取前三维 [vx, vy, yaw]，保持环境 batch 维度
传入 plan_trajectory(state, command, terrain, ...)
Parallelism 使用该 command 生成 root trajectory、touchdown 和 joint reference
command = env.command_manager.get_command("base_velocity")[:, :3]
ParallelismReferenceManager._command(env_ids)
        ↓
plan_trajectory(state, command, terrain, cfg)
        ↓
reference root / foot / joint trajectory
  • 课程扩大 vx/vy 后，下一次重规划必须使用更新后的 vx/vy。
  • yaw 直接使用当前固定范围 [-1, 1] 的 command。
  • 重规划不能缓存旧 command，除非该 cycle 明确要求保持同一 command。
  • teacher、student、reward 和 planner 必须读取同一个 command。
  • command tensor 必须保持 [num_envs, 3]，不能把线速度和 yaw 拆成不同接口。

十、预期训练行为

  • 训练初期同时面对完整 yaw 范围，但平移速度从低范围开始。
  • student 先学习低速下的前后、侧向和转向组合动作。
  • 线速度 reward 达标后，逐步扩大 vx/vy。
  • yaw 不等待课程，始终要求策略具备完整转向泛化能力。
  • teacher/student 混合逻辑不变，teacher 仍用于蒸馏稳定训练。

Go2Pvcnn/tracking/parallelism_tracking_env_cfg.py 保留作为旧任务兼容配置，不影响已有实验。

十二、不修改的内容

  • 不删除 yaw tracking reward。
  • 不改变最新 reward 权重和 std。
  • 不恢复 student 的 base_lin_vel observation。
  • 不把 reference root velocity 输入 student。
  • 不改变 teacher/student episode 级别接管。
  • 不改变 PPO、imitation loss、teacher ratio 和 std 衰减逻辑。
  • 不改变现有 termination 和 terrain curriculum。

十三、验证要求

  • 静态测试确认 planner 收到的 command 与 command manager 完全一致。
  • 测试 command 更新后，下一次重规划使用新 vx/vy/yaw，而不是旧缓存。
  • 使用 1024 个 Isaac Sim 环境运行 4 个 training iteration。
  • 验证 teacher observation、student observation 和 critic observation 维度正常。
  • 验证 collection、PPO update、curriculum 和 planner 均能完成。

十四、最终配置摘要

student observation:
  command = [vx, vy, yaw]
  base_lin_vel = disabled
  reference = disabled

reward:
  track_lin_vel_xy: weight=2.0, std=0.5
  track_ang_vel_z:  weight=1.5, std=0.5

curriculum:
  vx/vy: official reward-based curriculum
  yaw: no curriculum

yaw command:
  ang_vel_z = [-1.0, 1.0]

reference tracking:
  reward / metric / termination / distillation only
