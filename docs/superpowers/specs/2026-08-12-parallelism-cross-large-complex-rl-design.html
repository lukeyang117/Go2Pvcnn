Parallelism Small Cross + Large Avoidance + Complex Terrain RL 设计

日期：2026-08-12　目标 experiment：parallelism_tracking_cross_large_complex

1. 目标

新建一个 RL 任务，使同一个 policy 同时学习平地 small obstacle cross、复杂地形行走、 复杂地形上的少量 small obstacle cross，以及 large obstacle 避让。

policy 仍然跟踪 Parallelism 生成的 root、foot 和 joint reference。规划器负责生成 地形相关的 reference，RL 负责在 IsaacLab 物理环境中复刻 reference 并保持稳定运动。

新任务继承当前 small-obstacles RL 配置的速度课程、观测、reference tracking、 termination 和训练接口；不修改现有 flat、small-obstacles、ladder 任务。

2. 文件结构

dense flat 不是把所有 flat tile 都设置成 40 个障碍物，而是单独定义一个 terrain type。 这样可以避免 1024 个环境大规模复制密集障碍物。

4.2 其他 terrain

terrain 范围smalllarge地形课程
普通 flat、rough、slope、boxes、stairs 等 5 2 参与

其他 terrain 的 small/large obstacle 数量固定为 5 和 2，不随着 terrain level 变化。 terrain level 只改变 terrain generator 生成的地形难度。

5. 障碍物生成和 reset

障碍物只在创建 terrain 时生成一次：

创建 terrain
  → 根据 terrain type 确定障碍物数量
  → 使用固定 seed + 随机布局生成障碍物
  → 根据地形高度放置障碍物
  → 建立 semantic geometry 和 semantic map
  → 初始化 semantic raycaster

后续 reset
  → 只重置机器人、reference 和 episode 状态
  → 不重新随机障碍物
  → 不重新创建 USD obstacle prim

dense flat 的 40 个 small obstacles 也只创建一次。这样 reset 不会反复生成障碍物， 避免启动卡顿和运行时开销。

6. Dense flat 的环境比例和课程排除

dense flat terrain type 的 proportion 设置为约 0.0625。terrain importer 根据 terrain type 分配环境 origin；不通过每个 reset 的 Python 随机逻辑重新分配。

地形课程更新时：

dense_flat_mask = terrain_name == "flat_dense_small_obstacles"
normal_env_ids = env_ids[~dense_flat_mask[env_ids]]

只对 normal_env_ids 执行 terrain_levels_vel_semantic_plane_gate

dense flat 环境：

  • 不升级 terrain level；
  • 不降低 terrain level；
  • reset 后保持 dense flat terrain type；
  • 不因为 small obstacle cross 失败而切换到复杂 terrain。

普通 terrain 环境继续使用现有 Go2Pvcnn terrain curriculum：

  • 移动距离足够且 episode 成功时升级；
  • 移动距离不足、base contact 或 bad orientation 时降级；
  • terrain row/level 继续由 IsaacLab terrain importer 管理。

7. 速度课程

速度课程完全继承：

tracking/parallelism_small_obstacles_env_cfg.py

保留当前阈值：

root_pos_threshold   = 0.18
root_rot_threshold   = 0.45
joint_mean_threshold = 0.32
joint_max_threshold  = 1.0

速度课程和地形课程相互独立。速度课程只根据 Parallelism reference tracking 误差 调整速度等级；地形课程只根据 terrain level 结果调整普通环境的 terrain 难度。

8. Small obstacle cross

small obstacle 使用当前实现，不改变规划逻辑：

  • semantic ID 为 1；
  • touchdown 候选采样和 semantic margin 保持不变；
  • swing 足端高度继续根据高程图生成；
  • official collision geometry 继续检查 thigh、calf、foot；
  • active swing foot 安全落在 small obstacle 上时保留奖励；
  • dense flat 主要学习密集 small obstacle cross。

9. Large obstacle avoidance

large obstacle 使用 semantic ID 2，复用当前 Parallelism root 横向避让：

当前 root 平移速度
  → 沿速度方向构造检测矩形
  → 查询矩形内 semantic=2
  → 加权 mean_L 只决定左绕/右绕
  → 最近障碍物前向距离决定横向速度大小
  → 修改 root command
  → 原有 root Z/RPY、swing、IK 和 collision

初始参数：

large_obstacle_rect_width_m = 0.70
large_obstacle_rect_length_m = 1.20
large_obstacle_lateral_speed_max_mps = 0.25
large_obstacle_default_side = +1  # +1=向左，-1=向右

这套避让逻辑对 flat、rough、slope、boxes、stairs 等所有 terrain type 统一生效， 不为每种复杂地形复制一套 planner。

10. Reward 设计

不新增 large obstacle 专用 reward。只扩展和复用：

parallelism_geometry_collision

它调用 Parallelism official geometry collision：

当前 policy Go2 姿态
  → FK 得到 thigh/calf/foot 几何体
  → official_collision_mask
  → 查询 semantic/elevation terrain
  → active swing leg 碰撞判断
  → 产生 collision penalty

由于 Parallelism 的 obstacle semantic IDs 为 (1, 2)，该 reward 同时覆盖：

  • small obstacle：semantic_id=1；
  • large obstacle：semantic_id=2。

保留当前 reward：

  • reference joint position/velocity；
  • reference root position/rotation；
  • reference foot position；
  • active swing foot tracking；
  • active swing foot max error；
  • joint max tracking；
  • 基础速度、姿态、能量和接触相关 reward；
  • active_swing_foot_on_small_obstacle；
  • parallelism_geometry_collision。

large obstacle 的学习信号来自两部分：Parallelism 生成的绕行 reference，以及 parallelism_geometry_collision 的碰撞惩罚。

11. Observation 设计

沿用当前 small-obstacles RL observation，不新增 handcrafted large obstacle 输入：

  • policy state；
  • elevation map；
  • semantic map；
  • reference root position/rotation/velocity；
  • reference foot position；
  • reference joint position/velocity。

高程图提供 terrain geometry，semantic map 区分 small 和 large obstacle，Parallelism reference 提供 planner 已经做出的 root 横移和足端动作。

12. Termination

第一版继承当前 small-obstacles tracking termination：

time_out
base_contact
bad_orientation
parallelism_ref_root_z_too_far
parallelism_ref_projected_gravity_too_far
parallelism_ref_foot_z_too_far
parallelism_ref_joint_pos_too_far

不新增 large obstacle 专用 termination。large obstacle 初期主要通过 reference tracking 和 geometry collision penalty 学习，避免刚开始训练时因为 large obstacle 碰撞频繁 reset， 导致 terrain curriculum 和 velocity curriculum 无法提升。

13. GPU 并行和性能要求

  • terrain obstacle 创建只在初始化阶段执行，不在 reset 中创建。
  • terrain curriculum 使用 env ID mask 批量更新，不逐环境调用 Python planner。
  • semantic map、elevation map 和 collision reward 继续使用 Torch/GPU 批量计算。
  • large obstacle root avoidance 保持 O(B×H×W)，不遍历 Python 障碍物列表。
  • dense flat 只占约 1/16 环境，降低 40 个障碍物的总复制量。
  • 普通 terrain 每个 tile 只放 5 个 small 和 2 个 large obstacle。

15. 测试要求

  • 验证新配置可以正常 import 和 instantiate。
  • 验证 terrain generator 包含一个 dense flat terrain type。
  • 验证 dense flat 的 obstacle count 为 small=40、large=0。
  • 验证其他 terrain 的 obstacle count 为 small=5、large=2。
  • 验证 dense flat 比例约为 1/16。
  • 验证 obstacle geometry 只创建一次，reset 不重复创建。
  • 验证 dense flat 不参与 terrain curriculum。
  • 验证普通 terrain 继续使用 Go2Pvcnn terrain curriculum。
  • 验证速度 curriculum 参数与 small-obstacles 配置一致。
  • 验证 parallelism_geometry_collision 同时覆盖 semantic 1 和 semantic 2。
  • 使用 1024 环境执行短训练启动测试，确认 reset、reference planner 和 reward 不报错。
