Parallelism 平地 Root 固定高度设计

日期：2026-08-20　状态：待实现设计　范围：flat / flat_dense_small_obstacles
核心结论：平地类地形的 root 参考高度固定为 0.30m。小障碍物继续参与足端高度和碰撞规划，但不再参与 root 高度生成。

一、问题与根因

当前 planner 的平地 root 高度不是固定值，而是读取当前 stance 足端下方的高程，再加上 root_clearance_m：

stance_height = query_height(stance_foot_xy)
root_z = stance_height + root_clearance_m

当某条腿踩在小障碍物上时，查询到的 stance_height 包含小障碍物高度，root 参考轨迹就会被整体抬高。

同时，flat_dense_small_obstacles 当前没有被识别为平地。reference manager 只把名称严格等于 flat 的 terrain 视为平地，因此 dense flat 可能进入 terrain-following 分支，读取 root XY 下方的高程，同样会受到小障碍物影响。

需要避免的错误：不能通过删除语义高程图、删除 touchdown 高度或关闭碰撞检测来解决。问题只在 root 高度来源，不在足端规划本身。

二、目标行为

地形类型Root 高度策略小障碍物对 root 的影响其他地形跟随逻辑
flat目标高度固定为 0.30m不影响保留平地 roll/pitch 回正
flat_dense_small_obstacles目标高度固定为 0.30m不影响保留平地 roll/pitch 回正
rough、slope、boxes、stairs继续使用 terrain-following按现有复杂地形逻辑处理不修改

配置项：

flat_root_z_target_m: float = 0.30

三、Reference 时间与高度轨迹

→
第 1～23 帧

→

0.30m

每次 reset 或重规划时：

root_z_ref[0] = root_z_actual
root_z_ref[t] = smooth(root_z_actual, 0.30, t), 1 <= t < 24

第 0 帧继续用于保证 reference 与真实机器人对齐。第 1～23 帧回到固定高度，避免当前 root 因站在小障碍物上而把整个 reference 抬高。

root 的 XY 轨迹、yaw 轨迹、平地 roll/pitch 回正逻辑不变。

四、规划数据流

4.1 平地类地形

command
  ↓
root XY / yaw rollout
  ↓
flat_root_z_target_m = 0.30
  ↓
root reference
  ↓
foot touchdown / swing 高程查询
  ↓
IK 与几何碰撞检测

高程图仍然会进入足端规划，但不会进入平地 root 高度计算。

4.2 复杂地形

command
  ↓
root XY / yaw rollout
  ↓
root XY 下方高程查询
  ↓
terrain-following root Z 与 roll/pitch
  ↓
foot touchdown / swing / IK / collision

这条路径保持现有实现，不使用固定的 0.30m。

六、验证标准

  1. 在 flat terrain 中，把局部高程从 0.00m 改为 0.10m，root reference 的第 1～23 帧目标高度仍为 0.30m。
  2. 在 flat dense terrain 中，即使 root XY 正好位于小障碍物上方，也不能进入 terrain-following root 分支。
  3. reference 第 0 帧仍等于当前 IsaacLab 真实 root 状态。
  4. rough、slope、boxes、stairs 的 root Z 仍随高程图变化。
  5. standstill fallback 不再通过小障碍物高度抬高 flat 类 terrain 的 root。
  6. 现有足端 touchdown、swing clearance、IK 和 geometry collision 测试继续通过。
验收结果：平地上的小障碍物只改变腿和足端的规划约束，不改变 root 的默认参考高度。

七、范围边界

  • 本设计只解决 root 高度被 flat 类小障碍物抬高的问题。
  • 不改变 Parallelism 的 touchdown 候选采样半径。
  • 不改变 swing clearance 的配置。
  • 不改变 semantic obstacle 数量和 terrain 比例。
  • 不改变 RL 的 observation、reward、termination 或 curriculum 定义。
  • 不把复杂地形错误地当成固定高度平地。
